## Step 3: 심리 모델 3가지

### 1. 상호성 (Reciprocity) - 최우선

```
"가입 전에 먼저 체험 금고P 드릴게요"
"일단 체험해보시고 마음에 드시면 그때 입금하세요"
```
**적용**: 첫 대화에서 무조건 먼저 주기

### 2. 손실 회피 (Loss Aversion)

```
"오늘 가입 안 하시면 첫 입금 보너스 10% 혜택이 사라져요 ⏰"
"지금 입금하면 받는 금고P, 내일이면 못 받아요"
```
**적용**: 첫 인사 후 2번째 메시지

### 3. 사회적 증거 (Social Proof)

```
"이번 주에 32명이 첫 입금 보너스 받았어요 💰"
"어제 김OO님이 300만원 출금하셨어요"
```
**적용**: 혜택 설명할 때 숫자와 함께

## Step 5: Popup CRO

### 팝업 전략 4가지

| 팝업 | 트리거 | 목표 |
|------|--------|------|
| 1. 신규 환영 | 페이지 진입 30초 후 | 가입 전환 |

| 3. 스크롤 기반 | 50% 스크롤 | 문의 유도 |
| 4. 가입 완료 | 가입 직후 | 첫 입금 유도 |

```

체험 금고P + 첫 입금 보너스 10%
```
