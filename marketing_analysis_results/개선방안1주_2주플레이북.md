# 1-2주차 플레이북

---

## 오늘 할 일 (순서대로)

1. 종이에 "VIP 10명" 이름 적기
2. 10:00 - VIP 10명에게 **첫 DM** 보내기
3. 답장 오면 바로 **클릭 유도** 보내기
4. 13:00 - WARM 30명에게 **첫 DM** 보내기
5. 16:00 - 1시간 동안 답장 없는 사람에게 **리마인더** 1번
6. 21:00 - 시트에 숫자 기록

---

## 목표 (입금 아님!)

- **목표 1**: 답장 받기 (한 마디라도)
- **목표 2**: 클릭 1번 만들기 (링크 누르기)

---

## 사람 분류

| 구분 | 설명 |
|------|------|
| VIP | 돈 잘 쓸 가능성 높은 10명 |
| WARM | 예전에 말 섞인 사람 |
| COLD | 예전에 씹었던 사람 |
| NEW | 오늘 새로 온 사람 |

---

## 복붙 템플릿 3개

### A. 첫 DM
```
안녕하세요! 먼저 체험용으로 금고P 드릴게요.
취향이 뭐예요? 슬롯/바카라/스포츠 중에 하나만요.
```

### B. 답장 후 클릭 유도
```
오케이, 그 취향이면 이거 1분만 눌러서 체험해보세요.
여기 링크요: [링크]
```

### C. 1시간 미응답
```
혹시 바쁘셨죠. 하나만 골라주세요: 슬롯/바카라/스포츠?
```

---

## 밤 9시에 볼 숫자 3개

- **답장율** = 답장한 수 / 첫 DM 보낸 수
- **클릭율** = 링크 누른 수 / 첫 DM 보낸 수
- **진입율** = 시스템 들어온 수 / 링크 누른 수

---

## 막힐 때 처방

| 문제 | 해결 |
|------|------|
| 답장이 안 옴 | 질문이 3지선다인지, 첫 문장이 혜택 나열인지 확인 |
| 클릭이 안 됨 | 설명이 길다 → 템플릿 B로 바로 링크 |
| 진입이 안 됨 | 링크/첫화면/가입이 번거롭다 → UX 문제 |

## W2 (2주차) 핵심

- 목표: Alpha 10명 → Beta 50명
- 방법: Alpha가 친구를 데려오게 만들기

### 월요일 (D+8)
```
09:00 - W1 성과 정리 (답장율/클릭율)
10:00 - Alpha에게 초대 요청 (친구 1명)
14:00 - 2차 티저 (실데이터 숫자만)
16:00 - 첫 출금자에게 추천 요청
```

---

## 절대 룰

- 첫 메시지: **질문 1개 + 먼저 주기 1줄**
- 설명 금지: **2줄 + 링크 1개**
- 미응답 재시도: **1시간 후 1번, 24시간 후 1번** (총 2회)
- 숫자는 실데이터만
- 같은 사람에게 같은 문장 반복 금지
