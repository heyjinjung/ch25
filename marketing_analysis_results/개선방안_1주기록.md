# 1주차 기록 템플릿

> 구글시트에 아래 컬럼 복붙해서 사용

---

## 시트 1: DM_LOG (사람별 기록)

```
date | user_handle | nickname | segment | template_key | replied | click | joined | deposit | notes
```

| 컬럼 | 설명 |일자|
|------|------|------|
| date | 발송 날짜 |
| user_handle | 텔레그램 @ |
| nickname | 저장한 이름 |
| segment | VIP / WARM / COLD / NEW |
| template_key | 보낸 템플릿 (A1, B1 등) |
| replied | 답장 여부 (Y/N) |
| click | 링크 클릭 (Y/N) |
| joined | 시스템 진입 (Y/N) |
| deposit | 입금 여부 (Y/N/unknown) |
| notes | 특이사항 |

---

## 시트 2: DAILY_SUMMARY (하루 요약)

```
date | total_sent | replies | clicks | joins | reply_rate | click_rate | best_template | tomorrow_change
```

| 컬럼 | 설명 |
|------|------|
| date | 날짜 |
| total_sent | 오늘 첫 DM 보낸 수 |
| replies | 답장한 사람 수 |
| clicks | 링크 누른 사람 수 |
| joins | 시스템 진입한 수 |
| reply_rate | replies / total_sent |
| click_rate | clicks / total_sent |
| best_template | 오늘 가장 먹힌 템플릿 |
| tomorrow_change | 내일 바꿀 것 1개 |

---
