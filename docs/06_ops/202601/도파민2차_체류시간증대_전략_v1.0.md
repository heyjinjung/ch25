## 2. 주사위 (Dice)
**핵심 전략: 속도감 있는 플레이와 고위험 베팅 옵션**

### 2-1. 야수 모드 (Double Up / Gamble)
- **개요**: 승리 시 상금을 즉시 수령하지 않고, 획득한 금액 전액을 걸고 **"2배 or 0원"** 미니게임(50:50)에 도전할 기회를 제공(3초 제한).
- **효과**: 1판이 끝나는 시간을 "결과 확인" → "의사 결정"으로 연장. 승리 직후 도파민이 최고조일 때 추가 액션을 유도.
- **구현**:
    - Frontend: 승리 모달 내 [수령하기] vs [2배 도전하기] 버튼 분기.
    - Backend: `DiceService` 내 `double_up` API 엔드포인트 신설.

### 2-2. 자동 사냥 (Auto-Roll)
- **개요**: **[10회 자동], [50회 자동]** 버튼 추가. 클릭 시 결과창이 빠르게 넘어가는 것을 '관전'하는 모드.
- **효과**: 반복 클릭의 피로도를 없애 잔존 토큰을 모두 소진하게 만듦. 멍하니 화면을 바라보는 슬롯머신 심리(Zone out) 유도.
- **구현**:
    - Frontend: Loop 로직 구현 + 서버 부하 방지용 미세 딜레이(0.5s~1s) 준수.

### 2-3. XP 리스크 베팅 (XP High Roller)
- **개요**: 토큰뿐만 아니라 **시즌 XP(경험치)**를 걸고 승부. 승리 시 대량의 XP 획득, 패배 시 XP 차감.
- **효과**: 고레벨 유저들에게 긴장감을 부여하고 시즌패스 레벨업 욕구를 자극.
- **구현**: `SeasonPassService`와 연동하여 XP 차감(Reduce) 및 보상 로직 추가.

## 4. 시스템 공통 (System Wide)
**핵심 전략: 소셜 증명 및 연결성 강화**





### 4-2. 게이트 연쇄 보상 (Chain Reaction)
- **개요**: '오늘의 게임' 플레이 시 타 게임 입장권 지급 (예: 주사위 5판 → 룰렛 티켓 1장).
- **효과**: 한 게임만 하고 나가는 유저를 다른 게임으로 자연스럽게 이동(Funnel)시킴.
- **구현**: `MissionService` 일일 미션과 연동하거나 별도 게이트 로직 적용.

### 4-3. 원장 기반 업적 (Instant Achievement)
- **개요**: 실시간으로 `Ledger`(자금 흐름)를 분석해 "누적 1만 포인트 달성!" 팝업과 함께 즉시 보상.
- **효과**: 예기치 않은 보상(Unexpected Reward)으로 게임 지속 동기를 부여.
- **구현**: 비동기 워커가 `user_game_wallet_ledger` 집계 후 알림 발송.

## 5. 감각적 연출 (Sensory Stimulation)
**핵심 전략: 뇌를 자극하는 직접적인 피드백**

### 5-1. 보상 등급별 연출 차별화 (Tiered Visual FX)
- **개요**: 당첨 금액 규모에 따라 **Small / Big / Mega / Jackpot** 4단계로 연출 분리.
- **상세**: 상위 등급일수록 애니메이션 지속 시간이 길고, 더 화려한 파티클/카메라 쉐이킹 적용.
- **효과**: 상위 연출을 보기 위한 시각적 욕구 자극.

### 5-2. 사운드 디자인 (Sound Design)
- **청각적 각성**: 보너스/피버 모드 진입 시 BGM 템포 가속(1.2x) 및 고주파음 믹싱으로 심박수 상승 유도.
- **긍정 피드백 Loop**: 10원짜리 소액 당첨에도 경쾌한 숏 사운드(Ding!)를 송출하여, 침묵 구간 없이 뇌에 지속적인 보상 신호 전달.

## 6. 보상 구조 강화 (Reinforcement)
**핵심 전략: 확률적 보상 패턴의 심리학적 설계**

### 6-1. 멀티레벨 강화 (Multi-level Reinforcement)
- **개요**: 3중 레이어 보상 구조 운영.
    1. **Small Win**: 빈번한 소액 보상 (이탈 방지)
    2. **Jackpot**: 희귀한 대박 (장기 목표/꿈)
    3. **Bonus Game**: 중간 목표 (Pick k of n 방식의 미니게임)
- **효과**: 언제 끊어야 할지 모르게 만드는 '몰입 상태(Flow)' 유지.
- **구현**: 백엔드에 보너스 게임 로직(가중치 적용) 추가.
