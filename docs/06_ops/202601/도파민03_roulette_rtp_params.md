# Roulette RTP Tuning Parameters

이 문서는 2026년 1월 보상 개편(Phase 1)의 일환으로 수행되는 룰렛 확률 조정의 구체적인 수치를 정의합니다.
관리자(Admin)는 이 값을 참조하여 어드민 패널에서 룰렛 확률을 수동으로 설정하거나 검증할 수 있습니다.

## 1. 조정 목표
*   **재미 요소 강화**: '꽝' 경험을 줄이고, 당첨(특히 5천원) 경험을 확대하여 리텐션율 제고.
*   **재화 경험 단순화**: `CC_COIN`(씨씨코인) 유지.

## 2. 변경 상세 (Target Values)

스크립트(`scripts/tuning_roulette_rtp.py`)는 `ROULETTE_COIN` 타입의 룰렛 설정에 대해 아래 규칙을 적용합니다.

### A. 꽝 (Lose/Fail)
*   **대상**: `reward_type="NONE"` AND `reward_amount=0` (label: "꽝")
*   **변경 규칙**: 기존 가중치(Weight)의 **50% 수준으로 감소**
*   **예시**:
    *   기존 Weight: `100` -> 변경 Weight: `50`
    *   기존 Weight: `15` -> 변경 Weight: `7`

### B. 5000 포인트 (High Reward)
*   **대상**: `reward_type="POINT"` AND `reward_amount=5000`
*   **변경 규칙**: 기존 가중치(Weight)의 **200% 수준으로 증가 (2배)**
*   **예시**:
    *   기존 Weight: `10` -> 변경 Weight: `20`

### C. (유지) CC_COIN
*   **변경 없음**: 기존 씨씨코인 슬롯은 그대로 유지됩니다.

## 3. 적용 방법 (Admin Manual)
스크립트를 사용하지 않고 관리자가 직접 설정할 경우:
1.  Admin Page > Roulette Management 접속
2.  `Coin Roulette` (코인 룰렛) 설정 선택
3.  **Segments (슬롯)** 탭에서 위 규칙에 따라 `Weight` 값 수정
4.  저장 (Save)
