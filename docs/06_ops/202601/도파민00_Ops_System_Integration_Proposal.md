## 🧐 개요 (Overview)

현재 작성된 `도파민01~06` 가이드들은 **"What(무엇을 할 것인가)"**에 집중되어 있습니다.
여기에 **RTP의 "Strategy(구체적 시나리오/수치)"**와 **Ops Plan의 "How(운영 도구/실행)"**를 결합하여, 실전 배치가 가능한 수준으로 업그레이드할 것을 제안합니다.

### 핵심 통합 방향
1.  **Ops 구조 적용**: 모든 가이드의 '운영(Ops)' 섹션에 `Campaign` > `Plan` > `Task` > `Target List` 구조 명시.
2.  **RTP 시나리오 이식**: RTP에 정의된 11가지 위기/기회 시나리오(A~J)를 각 관련 가이드에 구체적으로 매핑.
3.  **수치 동기화**: RTP에 정의된 구체적 수치(XP 보상량, 지급 금액 등)를 가이드에 반영.

## 📈 개선 후 기대 효과

1.  **실행력 강화**: "무엇을 해야 할지" 고민하는 시간이 사라지고, "오늘의 Task"를 실행하는 구조로 전환됩니다.
2.  **개인화 극대화**: 단순 공지가 아닌, 유저 상태(시나리오)에 따른 1:1 타겟팅이 가능해집니다.
3.  **운영 효율성**: 모든 이벤트와 대응이 Admin 페이지 내에서 통합 관리됩니다.
