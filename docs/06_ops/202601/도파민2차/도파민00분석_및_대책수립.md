## 1. 현상 진단: 왜 "반응"이 없는가?

**진단 결과: 고마찰 / 저도파민 (High Friction / Low Dopamine)**

현재 시스템은 리텐션 장치(금고, 미션, 레벨업)가 과도하게 설계되어, 
도파민을 추구하는 유저들에게 **"즐거움"이 아닌 "숙제(Banking Task)"로 인식**되고 있습니다.

### 1.1 핵심 문제 (The Core Problem)
*   **도박꾼의 욕구**: "이겼다(Win)" -> "내 돈이다(Ownership)" -> "당장 쓴다(Action)".
*   **현재 시스템**: "이겼다" -> **"잠겼다(Lock)"** -> "미션을 해라(Labor)" -> "기다려라(Wait)".
*   **결과**: ** 즉시 강화(Immediate Reinforcement)** 루프가 끊겨, 
    신규 유저는 이 안전장치를 **"먹튀 방지용 장애물"**로 인식하고 이탈합니다.

### 1.2 재미/몰입 루프 분석 (Loop Analysis)
강화학습 관점에서 현재 시스템의 루프는 약화되어 있습니다.

1.  ** 즉시 강화 루프 (Short Loop)**: 
    *   *Ideal*: Trigger(무료게임) -> Action(플레이) -> Reward(즉시 보상) -> Investment(재베팅)
    *   *Current*: Reward가 '잠금' 상태로 주어져 **재베팅(Investment)으로 이어지지 않음.**
2.  **진행 루프 (Medium Loop)**:
    *   초반에는 '성장감(Progress)'보다 '규칙/조건(Constraint)'이 먼저 보여 거부감 발생.
3.  **사회/경쟁 루프 (Long Loop)**:
    *   실시간 당첨/환전 피드가 없어 "나 혼자 하는 유령 도시" 느낌을 줌.

## 2. 유저 경험(UX) 마찰 구간 분석
### 2.1 재미 점수표 (Fun Scorecard - User POV)
| 항목 | 현재 체감 | 문제 요약 |
| :--- | :--- | :--- |
| ** 즉시성 (Immediate)** | **낮음** | 승리해도 바로 못 씀. (가장 치명적) |
| ** 기대감/연출 (Drama)** | 중 | 결과 연출만 있고 '득템' 연출이 약함. |
| ** 통제감 (Control)** | 중하 | 규칙이 복잡하고 내 돈을 통제 못함. |
| ** 사회적 증거 (Social)** | **낮음** | 남들이 따는 게 안 보임. |
| ** 공정/신뢰 (Trust)** | 중 | 잠금/조건이 '먹튀'로 오해받기 쉬움. |

### 2.2 신규 유저 아이쇼핑 여정 (User Journey)
| 단계 | 유저 행동 | 시스템 응답 | 유저 감정 |
| :--- | :--- | :--- | :--- |
| **1. 진입** | 무료 체험 게임 플레이 | "2,000원 승리!" (Win) | 😍 기대감 상승 |
| **2. 확인** | 획득한 돈 확인 | "금고(Locked)에 적립됨" | 😐 1차 실망 (내 돈 아님) |
| **3. 시도** | 사용/출금 시도 | "미션 3개 완료 시 해금" | 😠 2차 짜증 (숙제 강요) |
| **4. 확인** | 출금 조건 확인 | "최소 1만 원부터 출금 가능" | 🤬 3차 분노 (희망 없음) |
| **5. 이탈** | 사이트 종료 | (회원 이탈) | "여기 가짜네." |

> **인사이트**: 리텐션 장치는 유저가 **충분히 몰입한 후(After Hooked)**에 작동해야 합니다. 
    현재는 **몰입 전(Before Hook)**에 작동하여 진입 자체를 차단하고 있습니다.

## 3. 대책 수립 (Action Plan)
신규 게임 개발보다 시급한 것은 **"앞문을 여는 것(Unlocking the Front Door)"**입니다.

### 3.1 [즉시 조치] 승리 직후 10초 살리기 (Immediate Action)
*   **CTA 단일화**: 승리 화면에서 "확인" 대신 **"바로 한 판 더"** 버튼을 최우선 노출.
*   **피드백 강화**: 승리 시 숫자만 보여주지 말고, "큰 글자 + 사운드 + 축하 문구"로 쾌감 극대화.
*   **투명성 확보**: 잠금/조건이 있다면 해제 조건과 남은 횟수를 한 화면에서 직관적으로 안내.

### 3.2 [단기 조치] 금고 잠금 해제 옵션 (Front Door Unlock)
소액 당첨금에 한해 "강제 저축" 경험을 제거해야 합니다. (정책 결정 필요)
*   **Option A (Buffer)**: 신규 유저의 최초 N승 소액은 '잠금' 없이 **즉시 사용 가능**하게 제공.
*   **Option B (Play Token)**: 현금성은 금고 SoT를 유지하되, **재경기용 티켓/코인**을 즉시 지급하여 루프 유지.
*   **효과**: "땄다 -> 건다 -> 또 땄다"로 이어지는 **몰입(Flow State)** 유도.

### 3.3 [운영 조치] VIP 수동 주입 & 사회적 증거 (Injection & Social Proof)
*   **VIP 핫라인**: 시나리오 11(External VIP) 대상자 8명에게 "금고 잠금 면제" 혜택을 수동 부여하여 즉시 활성화.
*   **Looking Glass (v1)**: 관리자용 `CrisisRadar` 데이터를 활용, 유저에게 **"실시간 당첨/출금 현황"** 피드 노출 (개인정보 마스킹).
    *   *내용*: "User33님이 방금 500,000원 출금!", "User01님이 골드키 획득!"
    *   *효과*: 유령 도시 탈피 및 경쟁심 유발.

## 4. 최소한의 안전장치: "스마트 마찰" (Smart Friction)
"모든 유저를 잠재적 범죄자 취급"하는 입구 봉쇄 대신, **출구 통제(Exit Control)** 및 **가드레일**을 적용합니다.

### 4.1 롤링(Rolling/Wager) 시스템 (표준 안전장치)
*   **개선**: 보너스 지급 시 "사용 불가"가 아니라 **"사용 가능, 단 출금 시 300% 롤링 필요"** 조건 부과.
*   **효과**: 유저는 당장 게임을 즐길 수 있고(도파민), 회사는 확률상 예산을 방어함(RTP).
### 4.2 체리피커 격리 (Shadow Ban)
*   **처방**: 의심 유저(가입 직후 패턴 이상)는 차단 대신 **"출금 지연 그룹"**으로 분류.
*   **효과**: 일반 유저는 쾌속 경험, 어뷰저만 정밀 심사 늪에 빠짐.
### 4.3 과몰입 방지 가드레일 (Responsible Gaming)
*   도파민 강화에 따른 부작용 방지를 위해 **세션 리마인더(시간 알림)** 및 **손실 경고** 장치 마련 권장.

## 5. 아키텍처 갭 분석 (Architectural Gap Analysis)
감사 보고서(Phase 2/3) 기반, 도파민 피벗을 위해 필요한 구조적 변화입니다.

| 영역 | 현행 (As-Is: Bank) | 개선 (To-Be: Casino) |
| :--- | :--- | :--- |
| **금고 (Vault)** | **SoT**: `vault_locked_balance` (강제 저축)<br>**Flow**: 모든 승리금 즉시 잠금
| **하이브리드**: `game_token_balance` (즉시 가용) 비중 확대<br>**Flow**: 소액은 티켓/코인으로 지급해 재베팅 유도 |
| **미션 (Mission)** | **승인**: `requires_approval=True`로 흐름 끊김<br>**대상**: 신규에게도 복잡한 미션 노출 
| **패스트트랙**: 소액/반복 미션은 `auto_claim=True`<br>**대상**: 신규는 '웰컴 보너스'만 심플하게 노출 |
| **데이터 (Data)** | **수동**: 외부 데이터 적재만 하고 액션 없음 
| **능동**: 외부 입금 감지 시 운영자에게 **즉시 알림(Alert)** 발송 |

### 6.1 현재(As-Is): "끝없는 결제 승인 대기의 늪" (All Friction)
| 기능 (Feature) | 유저 경험 시나리오 (The Pain) | 감정 상태 |
| :--- | :--- | :--- |
| **1. 웰컴 미션 (4종)** | ①게임 1판(100원) ②3판(100원) ③채널입장(500원) ④**내일 또 와**(2일차) <br> -> **"고작 700원 벌려고 내가 이걸 다?"** | 😤 **짜증** (보상 대비 노력이 큼) |

| **3. 금고 (Vault)** | "출금할래요." -> **[시스템]: 관리자 승인 대기중 (무기한)** <br> -> "언제 해주는 거야?" | 😡 **불신** (먹튀 의심) |
| **4. 레벨 시스템** | 게임 패배 -> "경험치 +10 획득!" (Season XP) <br> -> **"돈 잃었는데 경험치가 무슨 소용?"** | 😑 **무관심** (가치 없음) |

| :--- | :--- | :--- |

| **총평** | **"와, 정신 차려보니 30분 순삭했네."** | **중독 (Addiction)** |

## 7. 결론 (Conclusion)
**"문은 활짝 열고(Entry), 나가는 문에만 규칙을(Exit) 세우십시오."**
도박은 **혼돈(Chaos)**과 **위험(Risk)**, 그리고 **직관(Instinct)**의 영역입니다. 
신규 유저에게 "안전 금고"라는 이름의 장애물을 제안하지 마십시오.

1.  **신규 유저**: 날것의 위험과 보상(티켓/코인 즉시 지급)을 먼저 제공하여 **'재미'**를 느끼게 하십시오.
2.  **VIP 유저**: **"특별 대우(잠금 면제)"**로 시스템의 격을 보여주십시오.

이 두 가지 전략이 선행되어야, 이후 추가될 신규 게임들도 비로소 **'놀이터'**로서 기능할 것입니다.
