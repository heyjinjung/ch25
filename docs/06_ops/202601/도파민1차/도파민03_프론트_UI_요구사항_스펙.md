
# 도파민03 프론트엔드 UI 요구사항 스펙 (2026-01) - Final Simplified

## 0. 개요
"CC Casino"의 리텐션 핵심인 **재베팅(Re-betting)** 루프를 위한 **상점(교환소)** 전면 개편안입니다.
**5060 남성 타겟**에 맞춰, 불필요한 탭 이동(Depth)을 없애고 **"단일 페이지 교환소"**로 단순화합니다.

## 0.1 네비게이션 구조
*   **하단 메뉴 변경**: [홈] [게임] [금고] **[교환소]** [이벤트]
    *   기존 '상점' 명칭도 직관적인 **'교환소'**로 변경. (금고 돈을 티켓으로 바꾸는 곳)
*   **보상함 연결**: 교환소 헤더 우측에 **[📦 보상함]** 버튼 배치.

### 2.1 출금 게이지 (Cash-out Gauge)
*   **구현**: `VaultPageCompact.tsx`
*   **Visual**:
    *   **게이지**: Yellow/Amber 컬러의 "에너지 바" 디자인 적용.
    *   **Unlock**: 100% 달성 시 **"UNLOCKED"** 애니메이션 + **"CASH OUT NOW"** 버튼 활성화.
    *   **Logic**: `totalChargeAmount` (구매/활동 총액) 기반으로 퍼센트 계산 (`100,000 P` 기준 임시 적용).
*   **Feedback**: 버튼 클릭 시 Heavy Haptic 적용.
