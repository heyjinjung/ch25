## 1. 수정된 목적 (Revised Objective)
*   **Problem**: 외부 API 확인 불가. 신규 가입자가 "나 딴데서 좀 치던 놈이야"라고 주장해도 검증할 방법이 없음.
*   **Solution**: **"돈이 증명서다(Money Talks)"**. 외부 인증 대신, **첫 입금/누적 입금 패턴**을 분석하여 즉시 VIP 대우를 해주는 **[내부 승급 패스트트랙]**으로 전환.

## 2. 신규 유저 시나리오 (New User Flow)
*   **Scenario (Deposit-Based)**:
    1.  유저 가입 (레벨 1, 일반).
    2.  **Action**:
        *   **Condition A**: 첫 입금 **50만원 이상**.
        *   **Condition B**: (첫 입금일 기준) **7일 이내 누적 입금 300만원 달성**.
        *   **Trigger**: A와 B가 모두 충족되는 순간 즉시 발동.
    3.  **System**: `ExternalRankingUpdate` 감지 -> 조건 충족 시 발동.
    4.  **Benefit**: **시즌 XP +500 포인트** 즉시 지급 (Level Boost) + **[VIP 승급 모달]** 팝업 트리거.
    5.  **Ops**: 담당자에게 "잠재적 큰손 등장" 알림 (텔레그램).

## 3. 리스크 대응 및 운영 (Ops with Admin Tools)
> **Q. "체리피커와 큰손을 어떻게 구분하고 관리하나?"**
> **A. 별도의 자동화 시스템 개발 없이, 현재 구현된 [Admin > 세그먼트 관리] 기능을 적극 활용합니다.**

### 3.1. 운영자 판단 기준 (Segment & Tags)
> **⚠️ 중요**: `WHALE` 세그먼트는 시스템 자동 계산(Dynamic) 영역이므로, 운영자가 수동 설정할 때는 **`VIP` 세그먼트와 `Tag`를 조합**하여 관리합니다.

*   **👑 큰손 (WHALE)**
    *   **기준**: **첫 입금 50만 이상 AND 7일내 누적 300만 이상.**
    *   **Action**:
        1.  **세그먼트**: `VIP` 로 변경 (Admin > UserSegments).
        2.  **태그**: `#WHALE` 또는 `#큰손` 추가 (Admin > Users > Edit).
    *   **효과**: 운영자 리스트에서 태그로 식별 가능, **VIP 전용 UI (Gold Theme)** 적용.

*   **🍒 체리피커 (CHERRY_PICKER)**
    *   **기준**: 소액 입금 반복 + 즉시 출금 (시스템이 놓친 정성적 패턴).
    *   **Action**:
        1.  **세그먼트**: `AT_RISK` 로 변경 (관리 대상).
        2.  **태그**: `#체리피커` 또는 `#BAD` 추가.
    *   **효과**: `AT_RISK` 필터로 모니터링, **출금 30분 지연** 페널티 적용.

### 3.2. 피로도 없는 운영 루틴
*   **Morning Routine**: `VIP` 세그먼트 조회 -> `#WHALE` 태그 유저 확인 -> 텔레그램 인사.
*   **Defense Routine**: 출금 요청 시 유저가 `AT_RISK` 세그먼트면 30분 지연 처리 (매뉴얼 대응).

### 5.1. Backend Logic (`AdminExternalRankingService.py`)
**[IMPLEMENTED]** `AdminExternalRankingService.upsert_many` 메서드 내입 `_check_whale_qualification` 로직이 적용되었습니다.

```python
# app/services/admin_external_ranking_service.py

def _check_whale_qualification(self, db, user, current_external_total, now):
    # 1. 첫 인입 시점 및 금액 기록 (최초 1회)
    if user.first_deposit_at is None:
        user.first_deposit_at = now
        user.first_deposit_amount = current_external_total
        db.add(user)
        # Note: flush handled by caller or subsequent commits

    # 2. WHALE 달성 조건 검사
    # 조건 A: 첫 입금이 50만 원 이상
    # 조건 B: (기록 시작 후) 7일 내 누적 입금이 300만 원 이상
    first_amount = user.first_deposit_amount or 0
    days_since_start = (now.date() - user.first_deposit_at.date()).days
    
    is_big_first = (first_amount >= 500_000)
    is_fast_whale = (days_since_start <= 7) and (current_external_total >= 3_000_000)

    if is_big_first and is_fast_whale:
        # Idempotency: 중복 지급 방지
        profile = user.admin_profile
        current_tags = profile.tags or []
        if "#WHALE_REWARDED" not in current_tags:
            # A. Reward: 시즌 XP +500 (Level Boost)
            season_service = SeasonPassService()
            season_service.add_bonus_xp(db, user_id=user.id, xp_amount=500, commit=False)

            # B. Tagging: 보상 지급 완료 마킹
            current_tags.append("#WHALE_REWARDED")
            profile.tags = current_tags
            db.add(profile)

            # C. Notification: 관리자 실시간 통보
            msg = (
                f"🐋 **Whale Detected! (VIP Fast Track)**\n"
                f"- UserID: `{user.id}` ({user.nickname})\n"
                f"- First Deposit: `{first_amount:,} KRW`\n"
                f"- Total (7d): `{current_external_total:,} KRW`\n"
                f"- Action: Granted +500 XP & Alerted Admins"
            )
            send_ops_notification(msg, channel="admin")
```

### 5.3. UI 교정 디테일 (Technical Adjustments)
왕관 아이콘 및 뱃지 확장 시 레이아웃 깨짐 방지를 위한 필수 교정 사항입니다.

1.  **닉네임 가변폭 대응**: 뱃지가 길어지면 닉네임이 밀리므로, 부모 컨테이너에 `min-w-0`를 유지하고 닉네임의 `max-w`를 유동적으로 조정하거나 `flex-1`을 활용해 우선순위를 조정합니다.
2.  **이모지 수직 정렬**: 👑 이모지는 일반 텍스트보다 Baseline이 높으므로, `mb-0.5` 또는 `translate-y-[-1px]` 같은 미세 조정을 통해 "Lv" 텍스트와 수평을 맞춥니다.
3.  **SVG 전환 권장**: OS별 이모지 모양 파편화를 방지하기 위해, 최종 단계에서는 `lucide-react`의 `<Crown size={12} />` 또는 커스텀 골드 SVG 아이콘 사용을 권장합니다.

> 본 가이드는 **[RTP-4.2] 심화 라이프사이클 개입** 및 **[RTP-7] High-Touch 가이드**와 연동됩니다.

### 7.1. VIP 패스트 트랙 시나리오 (Revised)
시스템이 `ExternalRankingData`를 통해 입금액을 감지하면, 1차적으로 `User.total_charge_amount`가 갱신됩니다. 운영자는 이를 확인 후 `VIP` 세그먼트를 부여합니다.

*   **Scenario D. "귀하신 분" (The Whale)**
    *   **Signal**: `ExternalRankingData`(입금액) 증가 알림 (Audit Log).
    *   **Ops Action**: Admin에서 `#WHALE` 태그 추가 및 세그먼트 `VIP` 설정.
    *   **System**: 유저 접속 시 VIP 라운지 입장 연출 자동 트리거.

*   **Scenario G. "작업장 감지" (Cherry Picker)**
    *   **Signal**: 입출금 패턴 이상 (운영자 발견).
    *   **Ops Action**: Admin에서 `#체리피커` 태그 추가 및 세그먼트 `AT_RISK` 설정.

### 7.2. Admin Ops Plan 연동
*   **Campaign**: `Whale Hunting & Defense`
*   **Target List Source**:
    *   `High-Value`: `SELECT * FROM user_segment WHERE segment = 'VIP'` (and check tags for #WHALE)
    *   `Abuser`: `SELECT * FROM user_segment WHERE segment = 'AT_RISK'` (and check tags for #CHECK)
*   **Execution**:
    *   **Phase 2 Audit 준수**: `vault_locked_balance` 기반의 자산 가치를 최우선 지표로 삼습니다.
