# 도파민06 프론트엔드 구현 계획서 (Roadmap & Social/Security)

작성일: 2026-01-14  
범위: Social Proof 피드, Smart Friction UI, Admin 운영 화면

---

## 1) 목표 및 범위

- **Live Feed**: 하단 고정 피드로 "북적거림" 연출
- **보안 심사 UX**: 출금 지연/심사 상태를 명확히 안내
- **Admin UI**: 피드 템플릿 관리 및 Shadow Ban 컨트롤

---

## 2) 단계별 구현 로드맵

### 2.1 Live Feed 위젯

- 하단 고정 Marquee 또는 Ticker 컴포넌트
- 3초 간격 텍스트 롤링
- 피드 메시지 마스킹(`ji***`)
- WebWorker/Timer 분리로 메인 스레드 부하 최소화

### 2.2 Smart Friction UI

- 출금 상태별 메시지 처리
  - `ManualReview`: "보안 심사 중입니다"
  - `PendingReview`: "추가 확인이 필요합니다"
- 출금 버튼 비활성/설명 문구 추가

### 2.3 Admin UI

- Feed Controller
  - 템플릿 목록/수정
  - 봇 로그 ON/OFF 토글
  - 실시간 미리보기
- Shadow Ban Manager
  - 위험도 점수/상태 표시
  - 필터/검색 및 일괄 수정

---

## 3) 릴리즈 전략

- Live Feed는 홈 화면부터 적용 후 게임 페이지 확장
- 보안 심사 UI는 실제 상태 코드가 준비된 후 연결
