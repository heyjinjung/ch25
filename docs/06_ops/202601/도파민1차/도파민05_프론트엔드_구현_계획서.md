# 도파민05 프론트엔드 구현 계획서 (Events & Operations)

작성일: 2026-01-14  
범위: 도파민05_이벤트_장치_가이드 기준 (Golden Hour / Crisis / Segment Event / Ops UI)  
전제: 도파민01~04 UI/로직 구현 완료

---

## 1) 목표 및 범위

- **Golden Hour 체감 강화**: 시간대 진입/종료 연출, 배너/테마 전환
- **Segment Campaign 노출**: COMMON/VIP 대상 메시지/CTA 분기
- **위기 개입 연출**: Scenario 상황에서 즉시 개입 UI 노출
- **Admin Ops UI**: Golden Hour 토글/배수/대상자 실행 UI 연결

---

## 2) 단계별 구현 로드맵

### 2.1 상태 동기화

- `useEventStatus` 훅 구축
  - `GET /api/events/status` 폴링 (10s)
  - `isGoldenHour`, `multiplier`, `nextEventTime` 상태 제공
- 전역 상태 반영
  - 게임/홈/상단 배너에서 공통 사용

### 2.2 유저-facing UI

- Golden Hour 진입/종료 연출
  - 19:50/19:55 예열 배너
  - 20:00 전체 테마 전환 + "GOLDEN HOUR" 배너
  - 21:00 원상 복구 + TOP3 발표 슬롯(텍스트)
- Segment Campaign
  - COMMON: 금고 5,000P 달성/소진 시 전환 팝업
  - VIP: 월간 VIP 미션/골든아워 강조 배너
- 티켓/보상 체감
  - 배수 적용 시, 결과 화면에 배수 표시(예: x2.0)

### 2.3 Admin Ops UI (운영)

- Golden Hour 토글 (FORCE_ON/OFF)
- 배수 조정 UI (1.0~3.0)
- Target List 실행(시나리오 리스트 + 원클릭 실행)
- 마감 요약(KPI 스냅샷 입력)

### 2.4 관측/피로도 제어

- 배너/팝업 노출 빈도 제한 (세션/로컬 스토리지)
- 이벤트 노출/클릭 로그 전송 (KPI 측정용)

---

## 3) 릴리즈 전략

- Golden Hour UI부터 단계 적용
- Segment Campaign UI는 운영 데이터 검증 후 노출 확대
- Admin Ops UI는 운영팀 테스트 계정으로 먼저 오픈
