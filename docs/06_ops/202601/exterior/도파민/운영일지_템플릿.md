### 전체 동기화 프로세스

```powershell
# 전체 자동 동기화 (로컬 백업 → 서버 덤프 → 로컬 적용)
powershell -ExecutionPolicy Bypass -File scripts/sync_db_production.ps1
```

**동작 순서**:
1. **로컬 백업**: 현재 로컬 DB를 `local_backup_YYYYMMDD_HHmmss.sql`로 백업 (안전장치)
2. **서버 연결**: SSH 키 `~/.ssh/id_ed25519_vultr`로 서버 `149.28.135.147` 접속
3. **원격 덤프**: 운영서버 `xmas-db` 컨테이너에서 `mysqldump` 실행
4. **다운로드**: 덤프 파일을 로컬로 다운로드 (`server_dump.sql`)
5. **로컬 적용**: 로컬 `xmas-db` 컨테이너에 덤프 데이터를 임포트
6. **정리**: 임시 파일 삭제

### 수동 동기화 (선택)

```powershell
# 1. 서버에서 덤프만 (다운로드 포함)
powershell -ExecutionPolicy Bypass -File dump_db.ps1

# 2. 다운로드된 파일을 로컬에 수동 적용
type ch25_backup.sql.gz | docker exec -i xmas-db sh -lc "gunzip | mysql -u root -p2026 xmas_event"
```

## � 스크립트 상세 설명

### `scripts/daily_retention_report.py`

**기능**: 로컬 DB에서 데이터를 추출하여 콘솔에 리포트 출력

**옵션**:
| 옵션 | 설명 | 기본값 |
|:---|:---|:---|
| `--sync` | 실행 전 서버 데이터 동기화 | False |
| `--days N` | 분석할 기간 (일) | 14 |

**예시**:
```powershell
# 14일 평균 분석
python scripts/daily_retention_report.py

# 7일 평균, 서버 동기화 포함
python scripts/daily_retention_report.py --sync --days 7
```
