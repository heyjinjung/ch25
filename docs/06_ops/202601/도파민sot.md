## 3. 게임 보상 체계 변경 (Game Rewards)

> ⚠️ **핵심 제약**: 현재 시스템은 **외부 입금액 → 레벨 → 티켓 증정** 구조로, 플랫폼 내 입금 개념이 없어 "입금액 기반 롤링" 적용 불가.

### 3.1. 현황 (As-Is)
| 항목 | 설명 |
| :--- | :--- |
| **입장권** | 외부 레벨에 따라 **무료 티켓** 증정 (ROULETTE_COIN, DICE_TOKEN, LOTTERY_TICKET) |
| **승리 보상** | 게임 승리 시 `POINT` → **금고(Vault)에 잠김** |
| **문제점** | 유저가 딴 돈을 바로 쓸 수 없음 → 재베팅 불가 → 흥미 감소 |

### 3.2. 개편 방향 (To-Be): Casino Buy-In
| 변경 전 | 변경 후 |
| :--- | :--- |
| 금고 잔액 → 출금만 가능 | 금고 잔액 → **티켓 구매** 또는 출금 선택 가능 |
| 롤링 조건 없음 | **Soft Rolling**: 출금 시 "플레이 횟수" 또는 "금고 소비액" 검증 |
