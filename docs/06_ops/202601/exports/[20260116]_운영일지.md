## 💻 개발 및 시스템 개선 (Development & System Improvements)

### 1. 세그먼트 관리 페이지 필터링 및 검색 강화
- **목적**: 대규모 회원 리스트 관리 효율성 증대 및 운영자 UX 개선.
- **주요 변경 사항**:
    - **로컬 리스트 검색**: 테이블 내에서 별명, 텔레그램 핸들, 외부 ID, 유저 ID를 즉시 검색할 수 있는 기능 추가.
    - **세그먼트 정밀 필터**: '현재 세그먼트' 및 '추천 세그먼트'를 각각 드롭다운으로 선택하여 필터링 가능.
    - **통계 카드 연동**: 상단 통계 카드(VIP, 활성 등) 클릭 시 하단 드롭다운 필터와 테이블이 동기화되어 즉시 반영됨.
    - **필터 초기화**: 모든 검색어와 필터 조건을 한 번에 지울 수 있는 초기화 버튼 도입.
    - **서버 검색 분리**: 특정 개별 유저를 찾기 위한 서버 사이드 검색(Global Search)과 리스트 내 필터링(Local Filter)을 명확히 분리하여 성능 최적화.
- **기술적 해결**:
    - `useQuery`의 `searchTerm`과 로컬 필터용 `localSearchTerm` 상태 분리.
    - `tsc --noEmit` 검증을 통한 타입 안정성 확보 및 빌드 에러 해결.
    - 중복 export 및 누락된 React import 정리.

### 2. 룰렛 세그먼트 및 파편화 전략 구현 (Roulette Segmentation & Fragments)
- **목적**: 유저 등급(COMMON/WHALE/NEW)에 따른 룰렛 확률 차별화 및 '꽝' 경험 개선을 위한 조각(Fragment) 시스템 도입.
- **주요 구현 사항**:
    - **Backend**:
        - `ExchangeService` 및 `POST /api/exchange/craft` API 구현 (조각 -> 열쇠 교환).
        - `GameWalletService` 연동 및 트랜잭션 처리 로직 완성.
    - **Admin UI**:
        - 룰렛 설정(`RouletteConfigPage`)에 `Grade` 필드(COMMON/WHALE/NEW) 추가.
        - 리스트 내 등급 배지 표시 및 수정 모달 내 등급 선택 기능 구현.
    - **Frontend**:
        - **InventoryPage**: 조각 아이템(`GOLD_KEY_FRAGMENT`, `DIAMOND_KEY_FRAGMENT`) 표시 및 '제작하기(Craft)' 기능 구현.
        - **RouletteWheel**: 룰렛 보상 타입에 따른 아이콘(조각 포함) 매핑 및 렌더링 로직 적용.
        - **Assets**: 조각 아이콘 Placeholder(`gold_key_fragment.png`, `diamond_key_fragment.png`) 적용.
    - **Documentation**: 구현 계획서(`도파민2차_룰렛구현계획서_Part1_Segmentation_Fragments.md`) 현행화 완료.
