# ✅ 도파민04 프론트엔드 구현 작업 진행 체크리스트

**작성일**: 2026-01-14
**목적**: 도파민04(리텐션 장치)의 프론트엔드 구현을 위한 구체적인 가이드 및 체크리스트. 백엔드 구현 완료에 맞춰 사용자 경험(UX)을 극대화하는 연출과 로직을 포함함.

---

## 0) 핵심 디자인 원칙 (Premium Casino UX)

- **글래스모피즘(Glassmorphism)**: 투명도 있는 배경과 `backdrop-blur`를 적극 활용하여 고급스러운 UI 구현.
- **가독성(Accessibility)**: 배경과 텍스트의 대비(Contrast) 4.5:1 이상 유지 필수.
- **Micro-Animations**: 지급, 성공, 전환 순간에 `Framer Motion`을 활용한 부드럽고 묵직한 연출 적용.
- **모바일 최적화**: 텔레그램 인앱 브라우저 뷰포트(반응형) 고려 필수.

## 1) 기능별 구현 체크리스트

### 1.1 Ticket-Zero & Bailout (구제 모달)
**목표**: 티켓 소진 시 이탈을 방지하고 "부활"의 경험 제공.

- [ ] **감지 로직**: 
    - [ ] `GET /api/vault/status` 응답의 `recommended_action === "OPEN_VAULT_MODAL"` 감지.
    - [ ] 클라이언트 사이드에서 모든 티켓(`DICE`, `ROULETTE`, `LOTTERY`, `TRIAL`) 합이 0일 때 긴급 모달 준비.
- [ ] **Bailout 모달 구현**:
    - [ ] `WithdrawalConditionsModal.tsx` 스타일의 고사양 글래스모피즘 적용.
    - [ ] **1단계 (금고 잔액 > 0)**: "금고 잔액으로 티켓 구매" 유도 버튼 노출.
    - [ ] **2단계 (금고 0)**: "체험 티켓 받기 (Trial Grant)" 버튼 노출.
- [ ] **지급 애니메이션**: 
    - [ ] `POST /api/trial-grant` 성공 시 티켓 아이콘이 하단 지갑으로 날아가는 파티클 효과.

### 1.2 Today 카드 (원픽 미션)
**목표**: 홈 화면에서 "오늘 할 일"을 명확하게 카드 형태로 강조.

- [ ] **카드 컴포넌트**:
    - [ ] `GET /api/mission` 결과 중 `is_featured` 플래그가 있는 미션을 상단에 카드형으로 렌더링.
    - [ ] 루시드 아이콘 + 프로그레스 바 + 강조된 CTA 버튼 포함.
- [ ] **Copywriting 전략**: 
    - [ ] "미션 수행"이 아닌 "한 판 더"를 유도하는 제목 적용 (예: "오늘의 잭팟 찬스").

### 1.3 Streak (보물상자 트랙)
**목표**: 연속 출석을 시각적으로 즐거운 트랙 보상으로 구현.

- [ ] **트랙 UI**:
    - [ ] 7일 기준 가로형 트랙 위에 상자/아이콘 배치.
    - [ ] `claimable_day`에 해당하는 상자에 펄스(Pulse) 및 글로우 이펙트 적용.
- [ ] **Claim 핸들링**:
    - [ ] 수동 클릭 시 `POST /api/mission/streak/claim` 호출 및 결과에 따른 아이템 획득 팝업 노출.

### 1.4 VIP & Almost-VIP 훅
**목표**: 성취감을 자극하여 추가 플레이 유도.

- [ ] **진행도 가이드**:
    - [ ] 레벨 9 이상, 경험치 90% 달성 시 홈 화면 상단에 "Almost VIP" 배너 또는 텍스트 노출.
    - [ ] "한 판이면 VIP 달성!" 등 긴박함 있는 카피 적용.
- [ ] **VIP 테마 연동**:
    - [ ] `user.segment === "VIP"` 유저에게는 상단 헤더 및 프로필 영역에 Gold Glow 및 왕관 아이콘 자동 적용.

## 2) 기술적 유의사항 (Technical Note)

- **멱등성 처리**: 모든 Claim 버튼에 중복 클릭 방지(`disable` 처리) 및 `X-Idempotency-Key` 헤더 확인.
- **캐시 동기화**: `react-query`의 `invalidateQueries`를 호출하여 보상 수령 즉시 상단 잔액/지갑 숫자가 갱신되도록 처리.
- **피로도 관리**: Ticket-Zero 모달 등 팝업류는 `localStorage` 또는 세션 상태를 활용하여 단시간 내 반복 노출 제한.
