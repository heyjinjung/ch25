### 📋 메시지 구성 원칙

#### ✅ **반드시 포함할 것**
```
1. 개인화
   └─ 닉네임 + 최근 성과 (구체적 수치)

2. 긍정 강화
   └─ "잘했어요!", "대단해요!", "축하합니다!"

3. 구체적 다음 목표
   └─ "다음은 레벨 5 달성" (추상적 X)

4. 선택권 제공
   └─ "원하시면" / "시도해 보세요" (강압 X)

5. 커뮤니티 연결
   └─ 팀, 리더보드, 다른 유저와의 연결

6. 게임 중심
   └─ 보상은 결과 (중심이 아님)
```

#### ❌ **절대 하면 안 되는 것**
```
1. ❌ "한 판만 더!" (강박성)
2. ❌ "긴급! 오늘까지만!" (긴급성 조작)
3. ❌ "손해 보지 마세요!" (손실 회피 심리)
4. ❌ "다른 유저들은 벌어가고 있습니다" (비교 압박)
5. ❌ "정확한 확률/수익 약속" (도박 심리)
6. ❌ "입금 유도" (명시적/암시적)
```

### 💬 후속 대응 (답장)

**원칙**: 유저 답장 시 **1시간 내** 응대

#### 유형별 응대
```
Q: "게임이 어려워요"
A: "초보자 모드가 있습니다. 이걸 먼저 해보세요!"
   └─ 구체적 해결책 + 격려

Q: "왜 연승이 끊겼어요?"
A: "어제 미션을 못 하셨네요. 다시 시작하면 됩니다!"
   └─ 팩트 확인 + 재도전 유도

Q: "게임이 재미없어요"
A: "어떤 부분이 힘들었나요? 개선해 드리겠습니다."
   └─ 경청 + 실제 피드백 수집

Q: "복귀 보너스는?"
A: "[링크] 여기서 확인하실 수 있습니다. 축하합니다!"
   └─ 직접 링크 제공
```

### 📈 성과 측정

메시지 배송 후 다음 지표를 추적합니다:

```
1. 응답률 (Reply Rate)
   └─ 메시지 받은 유저 중 답장 비율 (목표: 20%+)

2. 재접속률 (Re-engagement Rate)
   └─ 메시지 후 24시간 내 게임 접속 비율 (목표: 40%+)

3. 실행율 (Action Rate)
   └─ 제안한 액션 수행 비율 (팀 가입 등, 목표: 30%+)

4. 부정 피드백 (Negative Feedback)
   └─ "스팸", "귀찮아요" 등 (목표: 5% 이하)
```
