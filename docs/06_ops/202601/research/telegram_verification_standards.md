# [Research] 텔레그램 미션 인증 및 검증 표준 리포트

## 1. 개요
텔레그램 Mini App 시장(Hamster Kombat, Catizen 등)에서 "채널 구독" 및 "링크 공유" 미션을 어떻게 검증하는지 분석하고, 현재 우리 시스템의 테스트 한계(연동 불가)에 대한 원인과 대안을 제시합니다.

## 2. 기능별 업계 검증 표준 (Industry Standards)

### A. 채널/그룹 입장 (Join Channel)
*   **표준 방식**: **Telegram Bot API (`getChatMember`)**
*   **작동 원리**:
    1.  유저가 "입장 확인" 버튼 클릭.
    2.  서버가 텔레그램 API에 *"이 유저(ID: 12345)가 이 채널(@channel)의 멤버니?"* 라고 질의.
    3.  텔레그램이 `member`, `administrator`, `creator` 응답 시 성공 처리.
*   **주요 사례**: 
    *   **Hamster Kombat**: 정확히 이 API를 사용합니다. 따라서 텔레그램 계정이 없거나 연동되지 않은 유저는 **절대** 보상을 받을 수 없습니다.
*   **우리 서비스 현황**: 
    *   **동일한 표준 방식(`viral.py`) 사용 중**.
    *   **문제점**: 테스트 계정(User 131)이 "가짜 계정"이라 텔레그램 ID가 없어서, API가 "누군지 모름"으로 에러를 뱉는 것뿐입니다.

### B. 링크/초대 공유 (Share / Viral)
*   **방식 1: 레퍼럴 트래킹 (Referral Tracking) - [정확도: 높음]**
    *   유저별 고유 링크(`t.me/bot?start=123`) 발급.
    *   친구가 **실제로 들어와야** 보상 지급.
    *   단순 "공유하기" 행위(링크 복사)만으로는 보상을 안 주는 경우가 많음.
*   **방식 2: 신뢰 기반 (Trust-Based) - [정확도: 낮음]**
    *   "공유하기" 버튼 클릭 시 `window.open(url)` 실행.
    *   앱은 유저가 실제로 공유했는지 기술적으로 알 수 없음 (텔레그램 클라이언트가 API 제공 안 함).
    *   **해법**: 버튼 클릭 후 **3~5초 쿨타임**을 두고 보상 지급. (대부분의 양산형 앱이 사용)
*   **우리 서비스 현황**: 
    *   Trust-Based 방식을 사용 중 (프론트에서 액션 전송).

## 3. "텔레그램 연동 자체 테스트"가 안 되는 이유
텔레그램 Mini App의 "연동(Auth)"은 **텔레그램 앱 안에서 실행될 때** 텔레그램이 던져주는 **`initData` (신분증)**를 서버가 받아서 "아, 너 누구구나" 하고 인식하는 과정입니다.

*   **일반 유저**: 텔레그램 앱 -> 앱 실행 -> `initData` 자동 전송 -> **로그인/연동 성공**.
*   **테스트 유저 (로컬/서버 스크립트)**: `initData` 없음 -> 서버가 강제로 만든 DB 데이터일 뿐임 -> **텔레그램 입장에선 "존재하지 않는 유령"**.

따라서, **"연동 자체 테스트"를 하려면 반드시 "실제 텔레그램 계정"으로 로그인을 1회 수행해야 합니다.** 가짜 데이터로는 구조적으로 "연동 테스트"가 불가능합니다.

## 4. 결론 및 제언
1.  **채널 구독 검증**: 우리는 이미 **업계 표준(API 검증)**을 따르고 있습니다. 코드를 고칠 필요는 없습니다.
2.  **테스트 방법의 전환**:
    *   **방법 A (정석)**: 개발자/기획자 본인의 **실제 텔레그램 계정**으로 서버 149에 로그인하여 테스트 수행. (가장 정확함)
    *   **방법 B (속임수)**: 앞서 제안한 **Bypass** 코드를 넣어, "가짜 유저도 통과한 척" 처리.

**핵심**: 다른 상용 앱들도 "가짜 유저"로 "채널 입장 검증"을 통과시키는 마법 같은 기술은 없습니다. 그들은 **모든 유저를 100% 텔레그램 로그인**시키기 때문에 이 문제가 없을 뿐입니다.
