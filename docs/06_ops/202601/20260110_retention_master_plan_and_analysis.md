## 💰 2. [Strategy] Profit-First (수익 최우선) 전략

**"퍼주는 운영은 끝났다. 30만원 넣으면 1만원(3.3%) 돌려주는 품격 있는 멤버십으로 전환한다."**

### 2-1. 유저 등급 재편 (Tier System)

| 등급 | 조건 | 대상 인원 | 운영 원칙 |
| :--- | :--- | :---: | :--- |
| **👑 VVIP (The Whales)** | 누적 1,000만↑ OR 주간 300만↑ | **1명 (User 33)** | **[전담 관리]** 관리자 핫라인, 무조건적 케어 |
| **💎 VIP (High Roller)** | 누적 100만↑ | **약 6명** | **[집중 케어]** 30만원 입금 시마다 보너스 |
| **🥇 GOLD (Mid-Tier)** | 누적 30만↑ | **약 3명** | **[승격 유도]** "조금만 더 하면 VIP" 넛지 |
| **👤 COMMON (Non-Payer)** | 누적 30만 미만 | **나머지** | **[방치/자연선별]** 입금 전까지 리소스 투입 0원 |

### 2-2. 보상 테이블 (VIP Only)

> **원칙**: 선입금 후지급 (Pre-paid Reward Only)

| 트리거 | 보상 내용 | 환급률(ROI) | 대상 |
| :--- | :--- | :---: | :--- |
| **100만원 충전** | 금고 **30,000원** 즉시 적립 | 3.0% | VVIP, VIP |
| **50만원 충전** | 금고 **15,000원** 즉시 적립 | 3.0% | VIP 이상 |
| **30만원 충전** | 금고 **10,000원** 즉시 적립 | 3.3% | GOLD 이상 |
| **VIP 승격 달성** | **골드키 5개** (축하 선물) | - | 신규 VIP |

## 📅 3. [Action Plan] 1/10 ~ 1/20 실행 로드맵

### Phase 1: 고래 보호 (Day 1-3)
*   **타겟**: User 33 (978만원), 커피사랑(2,553만원 등 외부 연동 시)
*   **액션**:
    1.  **핫라인 개설**: 텔레그램 1:1방 개설 후 "귀하는 최고 등급 VVIP입니다" 통보.
    2.  **특별 오퍼**: "오늘 100만원 추가 충전 시, **다이아몬드키 10개**를 개인 선물로 드립니다." (공지 X, DM O)

### Phase 2: 허리 강화 (Day 4-7)
*   **타겟**: 누적 14~29만원대 유저 (Mid-Tier)
*   **액션**:
    1.  **목표 제시**: "회원님, **OO만원만 더 충전하시면** 즉시 VIP 승격되며 금고 출금 한도가 해제됩니다."
    2.  **미친 척 제안**: "이번 주만! 30만원 충전하시면 **금고 1.5배 부스트(45,000원 상당)** 적용해 드립니다." (3명 한정)

### Phase 3: 자연 도태 유도 (Day 8-10)
*   **타겟**: 무과금/체리피커
*   **액션**:
    1.  **무대응**: 1,000원 달라는 문의, 미션 오류 문의에 기계적 응대 혹은 무시.
    2.  **공지 프레임**: "현재 VIP 입금 폭주로 일반 회원 응대가 지연되고 있습니다." (FOMO 유발)

## 🚫 4. 금지 사항 (Don'ts)

1.  **소액 출금 이벤트**: 1,000원/5,000원 출금 이벤트 **전면 폐지**. (브랜드 가치 하락)
2.  **무조건적 퍼주기**: 입금 없는 유저에게 "웰컴 보너스" 금지. (어뷰저만 꼬임)
3.  **전체 알림 남발**: VVIP가 소액 알림에 피로감을 느끼지 않도록 '타겟팅 DM' 위주로 소통.
