# 도파민05 프론트엔드 구현 작업 진행 체크리스트

작성일: 2026-01-14

## 0) 핵심 UX 원칙

- **피로도 관리**: 배너/팝업은 빈도 제한
- **분기 명확성**: 세그먼트별 메시지/CTA 분기 유지
