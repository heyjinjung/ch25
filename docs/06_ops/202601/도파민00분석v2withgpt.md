## 0) TL;DR (5줄)

- 현재는 “이겼다”가 “내가 지금 쓸 수 있다”로 변환되지 않아 **즉시 강화(Immediate Reinforcement)**가 약하다.
- 금고/미션/조건은 장기 리텐션 장치지만, **훅(몰입) 이전에 앞문을 잠가** 도파민 루프를 끊는다.
- 재미는 ‘보상 액수’만이 아니라 **연출·진행감·사회적 증거**로 증폭된다(현재 부족).
- 최우선은 **재플레이 루프(Win → Spend/Replay → Win)** 복원: “바로 다음 판”으로 넘어가는 감정 곡선을 설계.
- 단, 과몰입 리스크를 고려해 **가드레일(쿨다운/손실 경고/세션 리마인더)**도 함께 설계해야 한다.

## 1) 게임 유저 입장에서의 30초 요약(체감)

### 1.1 신규 유저의 솔직한 감정(텍스트)
- “오, 이겼네?”
- “근데… 내 돈이 아니야? 잠겨있어?”
- “미션을 해야 쓸 수 있어?”
- “최소 1만원부터?”
- “그럼 나는 언제 재미를 느끼지… 그냥 나가야겠다.”

### 1.2 ‘도박형 유저’가 기대하는 기본 루프
- **즉시성**: 이기면 바로 ‘쓸 수 있음’ → 다음 판 클릭
- **확률/연출**: 아슬아슬/연속/하이라이트
- **사회적 증거**: 누가 방금 땄는지, 나도 될 것 같은지

> 기존 보고서의 “Banking Task(숙제)” 진단은 이 기대 루프와 충돌하는 지점에서 발생한다.

---

## 2) 재미/흥미/몰입(중독도)을 ‘루프’로 분해

### 2.1 핵심 루프 3종(강화학습 관점)

1) **즉시 강화 루프(짧은 도파민)**
- Trigger: “무료/저비용 1판 가능”
- Action: 플레이
- Reward: 즉시 결과(승/패) + 즉시 사용할 수 있는 보상
- Investment: 다음 판 클릭, 티켓 소모, 세션 체류

2) **진행(Progress) 루프(중간 도파민)**
- 레벨/미션/배지/스탬프가 “조금씩 채워짐”
- 다음 목표까지 남은 거리(Progress bar)가 명확할수록 강함

3) **사회/경쟁 루프(확산/신뢰 도파민)**
- 리더보드, 팀 배틀, 실시간 피드(당첨/환전)
- “나도 저렇게 될 수 있다”는 **가능성의 증거**가 핵심

### 2.2 현재 시스템에서 루프가 약해지는 이유(요약)
- 즉시 강화 루프: 보상이 ‘잠김’/조건부로 보여서 **Reward → Spend**가 끊김
- 진행 루프: 장치는 많지만, 초반에는 ‘진행감’보다 ‘조건/규칙’이 먼저 보임
- 사회 루프: 유저에게 노출되는 실시간 증거가 부족해 **유령 도시** 느낌

## 3) 현재 시스템의 ‘재미 점수표’(유저 체감 기준)

> 점수는 “재미/흥미/몰입” 기준의 정성 평가이며, **고객 경험(UX) 관점**으로 작성됨.

| 항목 | 현재 체감 | 문제 요약 | 빠른 처방(개념) |
|---|---:|---|---|
| 즉시성(Immediate) | 낮음 | 이겨도 바로 못 씀 | 소액/초반만이라도 즉시 재플레이 가능 구조 |
| 기대감/연출(Drama) | 중 | 결과 연출/near-miss/연승 강조 부족 | 승리 하이라이트, 연승 스택, “거의 됐다” 연출 |
| 통제감(Control) | 중하 | 규칙이 복잡하게 느껴짐 | “다음 행동 1개”만 명확히 안내 |
| 진행감(Progress) | 중 | 미션/레벨이 ‘숙제’로 보일 수 있음 | 1~2개 핵심 목표만 전면 노출 |
| 사회적 증거(Social proof) | 낮음 | 나 혼자 하는 느낌 | 실시간 당첨/환전/획득 피드 |
| 공정/신뢰(Trust) | 중 | 잠금/조건이 오해를 부름 | “왜 잠겼는지/언제 풀리는지” 투명화 |

## 4) “고마찰/저도파민”의 구체 마찰 지점(유저 여정)

### 4.1 여정: 진입 → 1승 → 확인 → 다음 행동

1) 진입: 무료/체험 1판
- 기대감은 높음

2) 1승: “+2000원!” 같은 메시지
- 여기서 도파민 피크가 올라와야 함

3) 확인: 금고(Locked) 적립/조건 노출
- 피크가 급락(“내 돈 아님”)

4) 다음 행동:
- “다음 판” 대신 “미션/조건/최소 환전”이 먼저 보여 **행동 전환 비용** 증가

> 결론: ‘승리 직후 10초’에 다음 행동이 막히면, 가장 중요한 몰입 구간을 잃는다.

---

## 5) 대책: 재미/몰입을 올리는 실행안(스코프별)

### 5.1 즉시 조치(1~2일) — “승리 직후 10초”를 살리기

1) **승리 직후 CTA를 단일화**
- 승리 화면/모달에서 버튼은 1개가 최우선: `바로 한 판 더` (그 외는 secondary)
- 목적: 생각할 시간(마찰)을 없애고 다음 행동으로 연결

2) **피드백 강화(연출 3종 세트)**
- (A) 승리: 숫자만 말고 “큰 글자 + 소리/진동 + 짧은 축하 문구”
- (B) 패배: “다음 판이 더 유리” 같은 심리적 완충(과장 금지)
- (C) Near-miss: 아슬아슬 연출(공정성 침해 없이 시각적 강조)

3) **‘내 돈’ 인식 개선(투명성 UI)**
- 잠김/조건이 있다면, 이유/해제 조건/남은 횟수를 한 화면에서 끝내기
- 금고/미션/최소 환전이 분산돼 있으면 ‘사기’로 오해하기 쉽다

### 5.2 단기(1주) — “앞문 열기” 옵션 패키지

> 아래는 운영/정책 영향이 있을 수 있어 라벨을 붙인다.

A) **[정책 변경 제안] 초반 소액 ‘즉시 사용 가능’ 버퍼(Starter Liquidity)**
- 컨셉: 신규 유저에게 일정 구간(예: 최초 N승 또는 누적 M원 이하)은 잠금 없이 “즉시 재플레이 가능한 잔액”으로 제공
- 목적: 훅 형성 전(초반 1~3분)에는 ‘재미’가 우선
- 리스크: 먹튀/악용 → 방어는 별도 가드(계정 신뢰도/세션 제한/일일 캡)

B) **[정책 유지 가능] 잠김 상태라도 “재플레이 토큰”을 즉시 지급**
- 현금성은 금고 SoT 유지하되, 다음 판을 위한 티켓/코인/체험 토큰을 즉시 지급해 루프를 이어줌
- 장점: 현금성 지급 정책을 흔들지 않고도 즉시성 확보

C) **사회적 증거(Looking Glass) v1**
- 유저 화면에 “최근 당첨/환전/획득” 피드 노출(개인정보 마스킹)
- 팀 배틀/랭킹과 연결하면 신뢰 + 경쟁심 동시에 상승

### 5.3 중기(2~4주) — “진행/사회 루프”를 시스템화

1) **연승/연속 플레이 스택(Progress without chores)**
- 미션을 ‘해야만’이 아니라 ‘하면 더 빨라지는’ 보너스로 설계
- 예: 3연속 플레이 시 다음 판 티켓 1개 보너스(캡 필수)

2) **프로그레스 바 1개만 남기기(초반 UI 다이어트)**
- 초반에는 목표를 1개만: “오늘 5판만 하면 보너스”
- 미션이 많을수록 신규는 ‘숙제 앱’으로 인식

3) **실시간 피드 + 배지 + 공유**
- “누가 땄다”는 신뢰 장치
- “나도 땄다”는 공유 장치

## 6) 측정(지표) — ‘재미/몰입’이 올랐는지 증명하는 방법

### 6.1 최우선 KPI(게임성)
- **재플레이율**: 승리 후 60초 내 다음 판 비율
- **세션 길이**: 1세션 평균 플레이 횟수/체류 시간
- **D1 리텐션**: 다음날 재방문율

### 6.2 마찰 지표(UX)
- “승리→잔액 확인” 단계에서 이탈률
- “금고/조건 화면” 진입 후 이탈률
- “미션 화면” 체류 시간(길수록 좋은 게 아닐 수 있음)

### 6.3 사회 증거 지표
- 피드 노출 후 “게임 시작 클릭률” 변화
- 공유 버튼 클릭률(스토리/링크)

## 7) 실험 설계(A/B) 추천

1) 승리 직후 CTA 단일화 실험
- A: 현재 UI
- B: `바로 한 판 더` 1버튼 중심 + 나머지 secondary
- 기대: 승리 후 60초 내 재플레이율 증가

2) 사회적 증거 피드 실험
- A: 피드 없음
- B: 최근 당첨/환전/획득 피드
- 기대: 신규 세션 길이 + 신뢰 지표(가입/재방문) 상승

3) 초반 즉시성 옵션(정책 변경이 필요한 경우)
- A: 현행
- B: 초반 소액 유동성(또는 즉시 재플레이 토큰 보너스)
- 기대: 첫 세션 이탈 감소

## 8) 책임 있는 게임(과몰입 방지) 가드레일(필수)

본 문서는 ‘재미/몰입’을 올리는 관점이지만, 운영 리스크(과몰입/민원/규제)를 줄이기 위해 다음 가드레일을 권장한다.

- **세션 리마인더**: 10분/20분 단위로 “잠시 쉬었다 하시겠어요?”
- **손실 인지 강화**: 연속 손실 시 완충 문구 + 설정에서 한도/쿨다운 선택
- **쿨다운 옵션**: “오늘은 그만하기” 버튼을 숨기지 않기
- **투명성**: 잠김/조건/환전 규칙은 한 화면에서 이해 가능해야 함

## 9) 기존 문서와의 정합성 메모(참고)

- 기존 보고서: 고마찰/저도파민(앞문이 잠김) 진단에 동의하며, v2는 이를 ‘루프 관점’으로 재정리했다.
- SoT 문서: 현금성 보상은 금고 단일 SoT, 최소 환전 1만원 등은 그대로 존중한다.
- 따라서 “즉시 사용 가능” 제안은 **정책 변경** 또는 **현금성 대신 티켓/토큰으로 즉시성 확보** 중 하나로 선택해야 한다.
