# 2026-01-26_금고출금조건_정합성_검증_업데이트

이 문서는 금고 페이지의 출금 조건과 백엔드의 실제 구현 로직 간의 정합성을 검증한 결과입니다.

---

## 🏁 검증 결과 요약

| 항목 | 상태 | 내용 | 조치 필요 사항 |
|---|---|---|---|
| **출금 가능 잔액** | 🟢 정합 | `vault_locked_balance` 단일 SoT 사용 확인 | - |
| **티어별 최소 출금** | 🟢 정합 | [10k, 10k, 30k, 50k] 티어제 백엔드/프론트 동기화 확인 | - |
| **게임 플레이 조건** | 🔴 충돌 | FE: 최근 24시간 vs BE: 최근 3일 (범위 불일치) | FE 문구 수정 또는 BE 로직 조정 필요 |
| **사용 금액 조건** | 🔴 충돌 | FE: "누적 사용" vs BE: "오늘 사용" (`vault_spent_today`) | FE 문구 정정 필요 ("오늘 사용 금액") |
| **계좌/입금 인증** | 🔴 충돌 | FE: "계좌 점유인증" vs BE: "오늘 입금 확인" | 레이블과 로직의 명확한 통일 필요 |

---

## 🔍 상세 분석 데이터

### 1. 게임 플레이 조건 (Play Count)
- **FE (`WithdrawalRulesChecklist.tsx`)**: "최근 24시간 내 게임 X회 이상 플레이"로 표기.
- **BE (`V2VaultService.request_withdrawal`)**: 최근 **3일** 내 `GAME_PLAY` 또는 `MISSION_REWARD` 이벤트가 1건이라도 있는지 확인.
- **결과**: 사용자는 24시간 내 플레이를 안 하면 출금이 안 되는 줄 알지만, 실제로는 3일 전 플레이 기록만 있어도 백엔드 통과 가능 (사용자에게 더 엄격하게 안내 중).

### 2. 사용 금액 조건 (Spend Amount)
- **FE (`WithdrawalRulesChecklist.tsx`)**: "누적 X 포인트 이상 사용"으로 표기.
- **BE (`V2VaultService.get_vault_info`)**: `user.vault_spent_today` 필드를 `daily_vault_spent`로 내려줌.
- **결과**: "누적"이라는 표현은 전체 기간으로 오해될 소지가 큼. 실제 로직인 "오늘 사용액"에 맞춰 문구 수정 권장.

### 3. 계좌 점유인증 vs 오늘 입금 (Deposit Today)
- **FE (`WithdrawalRulesChecklist.tsx`)**: "입금 계좌 실명 확인 및 0원 인증 완료"로 표기.
- **BE (`V2VaultService.request_withdrawal`)**: `has_cc_deposit_today` (오늘 실제 입금 발생 여부)를 체크.
- **결과**: 로직상으로는 오늘 입금이 있어야 `eligible`이 되지만, 문구는 단순 계좌 인증으로 안내됨. 실제 입금 유도 정책인지 단순 인증 정책인지 재확인 후 일치시켜야 함.

### 4. 세그먼트별 동적 타겟 (Dynamic Targets)
- **BE (`V2VaultService.get_vault_info`)**:
  - 일반 유저: 30회 / 10,000점
  - AT_RISK 유저: 100회 / 30,000점
  - 고액 입금자 (300만↑): 0회 / 0점 (즉시 출금 가능)
- **결과**: 해당 로직은 백엔드에서 계산되어 FE로 전달되므로 정합함.

## 🧒 중학생도 이해하는 "왜 글자가 실제랑 다른가요?"

1.  **시간 약속이 달라요**: 
    *   화면에는 "오늘 게임 했니?"라고 물어보는데, 사실 백엔드(컴퓨터)는 "최근 3일 안에만 했으면 괜찮아~"라고 아주 너그럽게 봐주고 있어요. 큰 문제는 아니지만, 화면이 너무 엄격하죠?

2.  **'누적'인 줄 알았는데 '오늘' 거였어요**:
    *   "포인트 총 1만 점 썼니?"라고 물어봐서 어제 1만 점 쓴 친구가 출금하려는데 안 될 수 있어요. 왜냐하면 컴퓨터는 "아니, **'오늘'** 1만 점 썼는지를 물어본 거야"라고 생각하거든요. 문구를 "오늘 사용한 금액"으로 바꿔야 오해가 없겠죠?

3.  **인증인 줄 알았는데 '오늘 저금'이었어요**:
    *   화면에는 "네 계좌가 맞는지 인증해줘"라고 하는데, 실제로는 "오늘 우리 은행(금고)에 돈을 조금이라도 넣었니?"를 체크하고 있어요. 인증만 하면 끝인 줄 알았는데 돈을 넣어야 출금이 되니까 사용자가 당황할 수 있어요.
