# 유저 V2 Native SoT 정책 및 데이터 정합성 보고서

**최종 수정일**: 2026-01-27
**상태**: 🟢 V2 Native 단일 SoT 확립 완료

## 1. 정립된 V2 Native 단일 SoT 원칙
본 프로젝트의 유저 데이터 관리 원칙은 이제 **"V2 Native 테이블 중심의 단일 SoT"**를 지향합니다.

- **핵심 자산(금고)**: V2 금고 자산(`user.vault_locked_balance`)이 진실의 원천입니다.
- **기본 정보**: 유저 ID, 닉네임, 텔레그램 정보 등은 V2 유저 체계를 기준으로 관리합니다.
- **V2 테이블(`v2_user`)의 역할**: V2 고유 식별자(`cc_id`) 기반의 **V2 Native 마스터**이자, V2 전용 기능을 위한 **핵심 모델**입니다.

## 2. 필수 정합성 규칙 (Inviolable Rules)

| 항목 | 상세 규칙 | 비고 |
| :--- | :--- | :--- |
| **단일 ID (Same ID)** | `v2_user.id`는 V2 통합 ID와 반드시 일치해야 함. | V2 Sync 시 명시적 ID 승계 필수 |
| **식별자 일치** | `v2_user.cc_id` == V2 통합 식별자 | V2 내부 식별자 체계 일원화 |
| **이중 쓰기(Mirroring)** | V2에서 자산/정보 변경 시, V2 및 통합 테이블 양쪽에 동일하게 반영함. | V2 어드민 호환성 유지 |

## 3. 조치 및 검증 내역
- **ID 불일치 교정**: 'cc001' 유저의 V2 ID가 16이었던 오류를 삭제 후, 레거시 ID인 **17**로 일치시켜 재생성 완료.
- **로직 수정**: `V2UserService`의 동기화 로직에서 레거시 ID를 강제 할당하도록 수정하여 향후 불일치 가능성을 원천 차단함.

## 4. 향후 로드맵
- V2 서비스가 완전히 안정화되는 시점에 V2 Native 체계로의 완전 전환을 완료함. 현재는 **V2 데이터 정합성을 최우선**으로 함.
