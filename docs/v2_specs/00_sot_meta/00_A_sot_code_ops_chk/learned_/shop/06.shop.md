    - 🟢 [DB 정합]: `v2_shop_order`, `v2_exchange_log` 등 신규 스키마는 정책과 일치함.

    2. 상점 조회 API에 Config Null Check 및 Fallback/Alert 추가.

## 4. 알기 쉬운 불일치 설명 (For Beginners)

### 🔴 1. "돈 안 낸 손님도 물건을 살 수 있어요!" (Strict Vault Policy 미적용)
- **무슨 문제인가요?**: 7일 동안 입금을 안 하면 '제재' 상태가 되어 상점을 못 쓰게 막아야 한다는 규칙이 있어요.
- **실제로는요?**: 규칙은 있는데 가게 문지기(코드)가 검사를 안 해요. 제재된 사람도 몰래 들어와서 물건을 살 수 있는 상태예요.
- **해결책**: 가게 문 앞에서 "손님, 입금 확인 좀 하겠습니다"라고 검사하는 로직을 코드로 짜 넣어야 해요.

### 🟡 2. "진열대가 텅 비어버릴 수 있어요!" (Empty Shop Risk)
- **무슨 문제인가요?**: 상점 물건 목록을 적어둔 장부(Config)가 있어요.
- **실제로는요?**: 만약 운영자가 실수로 장부를 잃어버리거나 백지로 만들면, 가게에 들어왔을 때 아무 물건도 안 보이고 텅 빈 화면만 나와요.
- **해결책**: 장부가 비어있으면 운영자한테 빨간 불(알람)을 켜주거나, "준비 중입니다"라고 안내판이라도 보여줘야 해요.
