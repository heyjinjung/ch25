# Golden V2: 지연 대응(Latency Mitigation) 생존 전략 설계서

**작성일**: 2026-01-28
**상태**: SoT (Phase 4)
**대상**: BE/FE/아키텍트

---

## 1. 개요 (Overview)
외부 API/CSV 입금 데이터의 4~12시간 지연을 기술적/심리학적으로 극복하기 위한 설계입니다.

## 2. '선지급 후검증' 레이어 (Trust-based Governance)
- **유저 측 증거 제출 (User-Side Proof)**: 유저가 TX ID 또는 스크린샷을 직접 제출.
- **즉시 보상(Pre-payout)**: 제출 즉시 임시 보상을 지급하여 골든 타임 흥미 유지.
- **사후 대조(Post-verification)**: 실제 데이터 도착 시 백그라운드 워커가 대조하여 일치 시 확정, 불일치 시 차단.

## 3. Pending UX (Zeigarnik Effect)
- **확인 중 상태 시각화**: Redis를 이용해 대시보드에 **"입금 확인 중... (X시간 남음)"** 프로그레스 바 노출.
- **심리 효과**: 자신이 넣은 증거가 승인되기를 기다리게 함으로써 앱 삭제 방지(Lock-in).

## 4. 대기 시간 보상제 (Wait-time Bonus)
- **지연의 이득화**: 입금 확인이 늦어지는 1분당 X포인트를 보너스로 자동 누적.
- 유저에게 대기 시간이 '손실'이 아닌 '수익을 쌓는 과정'으로 치환됨.
