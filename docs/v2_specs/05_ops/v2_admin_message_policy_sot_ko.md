## 1. 목적 (Purpose)
V2 관리자 메시지 발송 정책과 타게팅 기준을 정의한다.

## 2. 범위 (Scope)
- 메시지 저장/팬아웃 규칙
- 타게팅 타입 및 대상 해석 기준

## 3. 용어 정의 (Definitions)
- 메시지: 운영자가 발송한 공지/DM/알림 템플릿
- 팬아웃: 대상 유저 집합을 계산하여 인박스에 적재하는 처리

## 4. SoT: 메시지 정책
1) 저장 모델
- 메시지 본문/타게팅 메타는 `v2_admin_message`에 저장한다.
- 사용자 인박스 항목은 `v2_admin_message_inbox`에 저장한다.

1.1) 운영 메시지 가드레일 (필수)
- 첫 문장은 "혜택 나열"이 아니라 질문으로 시작한다.
- 먼저 주기(상호성): 무료 체험/소액 선지급 문장을 1줄 포함한다.
- 사회적 증거 숫자는 반드시 실데이터만 사용하고, 집계 기준을 함께 기록한다.
- 손실 회피/마감 문구는 실제 마감이 있을 때만 사용한다.
- 미응답 재시도는 최대 2회(1시간 후 1회, 24시간 후 1회)로 제한한다.

2) 타게팅 타입
- ALL: 전체 유저
- SEGMENT: `v2_user_segment.segment` 매칭
- USER: 식별자/ID 기반 지정 발송
- TAG: 향후 확장(운영 필요 시 추가)

2.1) 온보딩 시퀀스(권장)
- 대상: `NEW` 세그먼트(가입 7일 이내, 텔레그램 연동, 입금 이력 없음) 우선
- 권장 흐름: 가입 직후(환영/질문) → 1시간 후(미충전 리마인더) → 24시간 후(최종 리마인더)
- 시퀀스 실행/집계 기준은 Asia/Seoul(KST) 및 운영일 09:00 리셋을 따른다.

3) 채널
- 기본 채널은 `INBOX`다.
- 채널 목록은 `channels` JSON 배열로 저장한다.

4) 통계
- 발송 대상 수는 `recipient_count`에 기록한다.
- 읽음 수는 `read_count`에 기록한다.
