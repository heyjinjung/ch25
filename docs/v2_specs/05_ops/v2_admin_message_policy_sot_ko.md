## 1. 목적 (Purpose)
V2 관리자 메시지 발송 정책과 타게팅 기준을 정의한다.

## 2. 범위 (Scope)
- 메시지 저장/팬아웃 규칙
- 타게팅 타입 및 대상 해석 기준

## 3. 용어 정의 (Definitions)
- 메시지: 운영자가 발송한 공지/DM/알림 템플릿
- 팬아웃: 대상 유저 집합을 계산하여 인박스에 적재하는 처리

## 4. SoT: 메시지 정책
1) 저장 모델
- 메시지 본문/타게팅 메타는 `v2_admin_message`에 저장한다.
- 사용자 인박스 항목은 `v2_admin_message_inbox`에 저장한다.

2) 타게팅 타입
- ALL: 전체 유저
- SEGMENT: `v2_user_segment.segment` 매칭
- USER: 식별자/ID 기반 지정 발송
- TAG: 향후 확장(운영 필요 시 추가)

3) 채널
- 기본 채널은 `INBOX`다.
- 채널 목록은 `channels` JSON 배열로 저장한다.

4) 통계
- 발송 대상 수는 `recipient_count`에 기록한다.
- 읽음 수는 `read_count`에 기록한다.
