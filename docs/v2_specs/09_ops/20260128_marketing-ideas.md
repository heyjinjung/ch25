# 2026-01-28: Marketing-Ideas 스킬 학습 및 XMAS Event System 적용

## 스킬 개요
- **이름**: marketing-ideas
- **설명**: SaaS/소프트웨어 제품을 위한 검증된 마케팅 전략, Marketing Feasibility Score (MFS)로 우선순위화.
- **역할**: 타당성 기반 아이디어 선택 (실행 가능/지연/무시).

## 주요 내용 요약
- **MFS 점수화**: Impact, Effort, Cost, Speed, Fit 차원 (범위 -7~+13).
- **아이디어 라이브러리**: Programmatic SEO, Referral Program 등 140개 패턴.
- **선택 규칙**: MFS ≤0 제외, 최대 5개 추천.
- **출력 형식**: 아이디어, MFS, 적용 방법, 결과, 리스크.
- **단계 편향**: Pre-Launch/Early/Growth/Scale별 점수 조정.
- **가드레일**: 아이디어 덤핑 금지, 점수 우선.

## XMAS Event System 적용
### 프로젝트 컨텍스트
- 이벤트/게임 앱: 사용자 유치/유지/성장.
- 단계: 운영 중 (성장 단계 추정).
- 제약: 예산 낮음, 비용 민감, 빠른 신호 우선.

### 추천 아이디어 (MFS 기반, 최대 5개)
1. **Programmatic SEO (+6)**: 콘텐츠 기반 트래픽 ("XMAS 이벤트 팁").
   - 적용: 블로그 템플릿, SEO 최적화.
   - 결과: 3-6개월 비브랜드 트래픽 ↑.
   - 리스크: 느린 피드백.

2. **Referral Program (+8)**: 친구 초대 보상 (티켓 +1).
   - 적용: 공유 버튼, 백엔드 코드 생성.
   - 결과: 성장 20-30%.
   - 리스크: 남용 방지.

3. **Social Media Content (+5)**: "XMAS 챌린지" 포스트.
   - 적용: 템플릿, 스케줄링.
   - 결과: 단기 트래픽 ↑.
   - 리스크: 콘텐츠 맞춤.

4. **Community Building (+7)**: Discord 커뮤니티.
   - 적용: 채널 생성, 이벤트 연계.
   - 결과: 유지율 ↑.
   - 리스크: 관리 부담.

5. **Email Sequences (+4)**: 리마인더 이메일.
   - 적용: 시퀀스 (가입→튜토리얼).
   - 결과: 재참여 10-15% ↑.
   - 리스크: 스팸 방지.

### 실행 계획
- **PLAN**: 컨텍스트 파악, 아이디어 선별.
- **PATCH**: 프론트/백엔드 통합 (콘텐츠/공유 기능).
- **VERIFY**: 정책 준수, 테스트.
- **SHIP**: 우선순위 실행, A/B 테스트.

## 결론
MFS로 타당성 평가, 프로젝트 성장 전략 강화. 심리 모델과 결합 가능.
