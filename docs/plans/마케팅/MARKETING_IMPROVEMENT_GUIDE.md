## Step 3: Marketing Psychology + Referral Program 적용

### 🧠 Part A: Marketing Psychology (심리 모델)

#### 즉시 적용할 3가지 심리 모델

---

#### 1️⃣ Loss Aversion (손실 회피) - PLFS 13점

**현재 문제**
```
"입플 10% 드립니다" (얻는 것만 강조)
```

**개선안**
```
"오늘 가입 안 하시면 입플 10% 혜택이 사라져요 ⏰"
"지금 충전하면 받는 골드, 내일이면 못 받아요"
```

**적용 위치**: 첫 인사 후 2번째 메시지

**PLFS 점수 계산**
| 요소 | 점수 | 이유 |
|------|------|------|
| Leverage | 4 | 손실 회피는 강력한 심리 트리거 |
| Fit | 4 | 카지노 업계에 매우 적합 |
| Speed | 3 | 즉시 메시지에 적용 가능 |
| Ethics | 3 | 허위 아닌 실제 마감 시 사용 |
| Implementation Cost | -1 | 카피만 수정하면 됨 |
| **합계** | **13** | **즉시 적용** |

---

#### 2️⃣ Social Proof (사회적 증거) - PLFS 12점

**현재 문제**
```
"저희 혜택 좋아요" (나만 말함)
```

**개선안**
```
"이번 주에 32명이 입플 받았어요 💰"
"어제 김OO님이 300만원 환전하셨어요"
"현재 147명이 지민코드로 활동 중이에요"
```

**적용 위치**: 혜택 설명할 때 숫자와 함께

**PLFS 점수 계산**
| 요소 | 점수 | 이유 |
|------|------|------|
| Leverage | 4 | 사회적 증거는 신뢰 형성에 핵심 |
| Fit | 4 | 카지노 유저는 "남들도 한다"에 민감 |
| Speed | 3 | 즉시 적용 가능 |
| Ethics | 2 | 실제 데이터 사용 시 윤리적 |
| Implementation Cost | -1 | 숫자만 추가하면 됨 |
| **합계** | **12** | **즉시 적용** |

---

#### 3️⃣ Reciprocity (상호성) - PLFS 14점

**현재 문제**
```
바로 가입 요청 (일방적 요구)
```

**개선안**
```
"가입 전에 먼저 무료 골드 10개 드릴게요"
"일단 체험해보시고 마음에 드시면 그때 충전하세요"
"질문 있으시면 먼저 답변 드릴게요, 부담 없이 물어보세요"
```

**적용 위치**: 첫 대화에서 무조건 먼저 주기

**PLFS 점수 계산**
| 요소 | 점수 | 이유 |
|------|------|------|
| Leverage | 5 | "받았으니 뭔가 해야지" 심리 강력 |
| Fit | 4 | 카지노 입플/보너스와 자연스럽게 연결 |
| Speed | 3 | 즉시 적용 가능 |
| Ethics | 3 | 실제 혜택 제공이므로 윤리적 |
| Implementation Cost | -1 | 순서만 바꾸면 됨 |
| **합계** | **14** | **최우선 적용** |

### 🔗 Part B: Referral Program (리퍼럴)

#### 양면 리퍼럴 구조 설계

```
┌─────────────┐         ┌─────────────┐
│  추천인     │ ──────▶ │  피추천인   │
│ (기존 회원) │         │ (신규 가입) │
└─────────────┘         └─────────────┘
      │                       │
      ▼                       ▼
 충전금 5% 골드           추가 입플 5%
```

#### 트리거 시점 (언제 추천 요청?)

| 시점 | 심리 상태 | 메시지 예시 |
|------|----------|------------|
| **첫 환전 성공 후** | 기쁨, 만족 | "축하드려요! 친구 소개하면 다음 충전 때 5% 더 드려요 🎉" |
| **3일 연속 접속** | 습관 형성 | "꾸준히 오시네요! 혜택 공유하실 친구 있으세요?" |
| **큰 당첨 후** | 흥분, 공유욕구 | "대박! 이 기분 친구랑 나눠보세요! 소개하면 5% 보너스" |
| **VIP 승급 시** | 자부심 | "VIP 되셨네요! 친구 초대하면 특별 혜택 드려요" |

#### 공유 방식 (텔레그램 전용)

**단순한 코드 방식 (권장)**
```
내 추천코드: JIMIN_[닉네임]
이 코드로 가입하면 입플 5% 추가!

👉 @jm956 으로 연락주세요
```

**왜 코드 방식인가?**
| 장점 | 설명 |
|------|------|
| 복잡한 링크 불필요 | 텔레그램에서 코드만 복붙 |
| 추적 용이 | V2 프로그램에서 코드로 추적 |
| 공유 쉬움 | 카톡/문자로도 쉽게 공유 |

#### 인센티브 구조 (티어드)

| 추천 수 | 추천인 혜택 | 피추천인 혜택 |
|---------|------------|--------------|
| 1명 | 충전금 5% 골드 | 입플 5% 추가 |
| 3명 | 충전금 7% 골드 | 입플 5% 추가 |
| 5명 | 충전금 10% 골드 + VIP 혜택 | 입플 7% 추가 |
| 10명+ | 충전금 15% 골드 + 특별 케어 | 입플 10% 추가 |

📌 Step 4: Launch Strategy + Onboarding CRO + Page CRO 연동
🚀 Part A: Launch Strategy (런칭 전략)
당신의 환경에 맞춘 ORB 프레임워크

채널 유형	일반	당신의 경우
Owned	이메일, 블로그	텔레그램 공식채널, V2 웹사이트
Rented	SNS, 앱스토어	텔레그램 개인채팅
Borrowed	인플루언서	기존 회원 추천 (리퍼럴)

🎯 V2 프로그램 런칭 5단계
1️⃣ Internal Launch (완료)

V2 프로그램 개발 완료
내부 테스트 완료
2️⃣ Alpha Launch (1주차)
목표: 핵심 VIP 10명 대상 테스트
방법:
- 기존 활성 유저 중 상위 10명 선정
- 개인 메시지로 "특별 테스트 참여" 요청
- 피드백 수집 및 버그 수정

메시지 예시:
"[닉네임]님, 저희가 새로운 골드 시스템을 준비했어요.
VIP분들께만 먼저 공개하는 거예요.
테스트 참여해주시면 골드 50개 드릴게요! 🎁"

3️⃣ Beta Launch (2-3주차)
목표: 50명으로 확장
방법:
- Alpha 참여자가 추천하면 바로 접근권 부여
- 공식채널에 티저 공개 (스크린샷, 기능 미리보기)
- "곧 공개" 느낌으로 기대감 조성

공식채널 티저:
"🔥 V2 골드 시스템 곧 오픈!
- 충전만 해도 골드 적립
- 골드로 현금 교환 가능
- 선착순 50명 먼저 체험 중

⏰ 정식 오픈: 2월 10일
지금 DM 주시면 먼저 사용 가능!"

4️⃣ Early Access Launch (4주차)

목표: 전체 기존 회원 대상 오픈
방법:
- 전체 회원에게 개인 메시지 발송
- 공식채널 대대적 공지
- 첫 주 한정 보너스 (손실 회피 적용)

메시지:
"🎉 V2 골드 시스템 정식 오픈!

✅ 충전금 2% 골드 적립
✅ 골드로 현금 교환
✅ 출석만 해도 골드 지급

⏰ 첫 주 특별 혜택: 골드 2배 적립!
(2월 17일까지만)

지금 바로 V2 시작하기 👉 [링크]"


5️⃣ Full Launch (5주차~)
목표: 신규 유저 유입 + 리퍼럴 활성화
방법:
- 모든 신규 가입자 V2로 자동 연결
- 리퍼럴 프로그램 본격 가동
- 정기 이벤트/업데이트로 모멘텀 유지
