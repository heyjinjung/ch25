# 필드 입력 및 데이터 그리드 디자인 가이드라인 (ISFJ Edition)

## 👤 타겟 페르소나 분석 (ISFJ 관리자)

* **성향**: 꼼꼼하고 책임감이 강하며, 실수를 극도로 경계함.
* **Pain Point**: 입력 필드가 난잡하게 흩어져 있어 무엇을 수정해야 할지 모르는 혼란, "내가 방금 뭘 바꿨지?" 하는 불안감.
* **Design Goal**: **"Error-Free, Focused, Clean"** (무결점, 집중, 정갈함).

---

## 1. 핵심 디자인 코드: "Focused Input & Clean Grid"

### A. 검색 및 필터 바 (Clarified Navigation)

화면 진입 시 가장 먼저 마주하는 곳으로, 깔끔한 첫인상을 줘야 합니다.

* **통합 검색바 (Floating Search)**:
  * 배경: `bg-zinc-900/50` + `backdrop-blur`.
  * 보더: `border-b border-white/5` (하단 경계만 표시).
  * 위치: 페이지 상단에 고정하지 않고 콘텐츠와 자연스럽게 어우러지게 배치.
  * 플레이스홀더: "아이디, 닉네임으로 검색..." (친절한 가이드 텍스트).

### B. 데이터 그리드 (Stress-Free Table)

ISFJ 관리자는 삐뚤빼뚤한 정렬을 참지 못합니다. **칼 같은 정렬**이 필수입니다.

* **헤더 (Sticky Header)**: 스크롤 시에도 항상 상단에 고정되어 "내가 어떤 항목을 보고 있는지" 잊지 않게 함. (`sticky top-0 z-10`).
* **셀 높이 (Row Height)**: `h-14` (56px) - *너무 좁으면 클릭 미스가 발생하고, 너무 넓으면 정보량이 부족함.*
* **텍스트 정렬**:
  * 텍스트(이름, 메모): **좌측 정렬**.
  * 숫자(금액, 횟수, 날짜): **우측 정렬** + `Monospace` 폰트.
  * 상태(뱃지): **중앙 정렬**.

## 2. 필드 입력 페이지 상세 가이드

### 👥 회원 관리 (User Management)

**"수정은 신중하게, 조회는 편안하게."**

1. **인라인 수정 제거 (No More Inline Edits)**
    * *문제*: 리스트 내에 입력창이 열려 있으면 "실수로 건드릴까 봐" 불안감을 줌.
    * *해결*: 모든 입력창을 텍스트로 전환. 수정이 필요하면 **[수정] 버튼 -> [모달]** 팝업 흐름으로 변경.
    * **모달 디자인**: 배경을 어둡게 처리(`bg-black/80`)하여 오직 수정 작업에만 집중하도록 함.

2. **컬럼 다이어트 (Column Diet)**
    * 정말 필요한 정보(ID, 닉네임, 상태, 최근접속, 보유자산)만 남기고, 나머지는 '상세보기'로 숨김.
    * **2단 셀**: 공간 절약을 위해 `[닉네임]` 아래에 작은 글씨로 `[@TelegramID]`를 배치.

### 🏆 외부 랭킹 (External Ranking)

**"숫자 비교의 용이성."**

1. **금액 시각화**
    * 0원인 데이터는 `text-zinc-700`으로 흐리게 처리(Noise Reduction).
    * 큰 금액은 `text-emerald-400` 등으로 은은하게 강조.
    * 콤마(,) 표시는 필수.

2. **필터 영역 단순화**
    * 무겁고 시꺼먼 필터 박스를 제거하고, 투명한 배경에 **Pill 형태의 탭**으로 변경.
    * "매칭됨 / 미매칭" 상태를 탭으로 분리하여 볼 수 있게 함.

### 🔢 세그먼트 관리 (User Segments)

**"맥락의 연결."**

1. **카드-리스트 인터랙션**
    * 상단 요약 카드('이탈 회원 12명')를 클릭하면 -> 하단 리스트가 부드럽게 필터링되는 애니메이션 적용.
    * 클릭된 카드에 `ring-2 ring-brand` 효과를 주어 현재 상태를 명확히 인지시킴.

2. **칩(Chip) 디자인**
    * 기존의 꽉 찬 배경색 칩은 눈이 아픔.
    * **Outlined Style**: `border border-indigo-500/30 text-indigo-400 bg-indigo-500/5` 스타일로 변경.

## 3. 구현 체크리스트 (Safety First)

* [ ] 실수로 값을 변경할 우려가 있는 인라인 입력창이 제거되었는가?
* [ ] 데이터를 삭제하거나 변경할 때 **"정말 진행하시겠습니까?"** 모달이 뜨는가?
* [ ] 테이블의 숫자 데이터는 모두 우측 정렬되어 자릿수 비교가 쉬운가?
* [ ] 검색 결과가 없을 때 "데이터가 없습니다"라는 친절한 안내 문구가 나오는가?

## 4. 2차 리팩토링 계획 (Secondary Refactoring Plan)

사용자 피드백을 반영하여, 1차 리팩토링 후에도 남아있는 **불규칙한 폰트 사이즈, 낭비되는 여백, 디자인 미반영 페이지**를 개선합니다.

### A. 타이포그래피 및 여백 최적화 (Global)

1. **폰트 계층 정규화 (Font Hierarchy Normalization)**
    * **헤더 타이틀**: `text-2xl font-bold tracking-tight` (기존 `text-3xl` 등 불규칙적 크기 통일).
    * **헤더 서브타이틀**: `text-sm text-zinc-400 font-medium` (불필요한 설명 제거 및 스타일 통일).
    * **테이블 헤더**: `text-xs font-semibold uppercase tracking-wider text-zinc-500` (크기 축소 및 일관성 확보).
    * **테이블 데이터**: `text-sm text-zinc-300` (기본값 통일). `Numeric` 데이터는 `tabular-nums tracking-tight` 적용.

2. **Compact Layout Rule**
    * **헤더 영역 축소**: 페이지 타이틀과 액션 버튼 사이의 여백을 `mb-6`로 표준화 (기존 `space-y-10` 등 과도한 여백 제거).
    * **밀도 높은 테이블**: 셀 패딩을 `px-4 py-3`으로 조정하여 한 화면에 더 많은 데이터 표시.

---

### B. 페이지별 리디자인 상세 (Specifics)

#### 👥 회원 관리 페이지 (User Admin)

* **문제점**: 디자인 토큰이 적용되지 않아 레거시 스타일(어둡고 투박한 테이블)이 유지되고 있음.
* **개선안**:
    1. **Card Prison 탈출**: 투박한 컨테이너 박스를 제거하고, 배경색(`bg-zinc-900`)에 자연스럽게 녹아드는 **Open Table** 스타일 적용.
    2. **Status Badge 개선**: 기존의 단순 텍스트/배경 배지를 `ring-1 ring-inset` 스타일의 세련된 배지로 교체.
    3. **Sticky Header 적용**: 스크롤 시 검색바와 테이블 헤더가 상단에 고정되도록 `sticky top-0` 적용.
    4. **Action Column 아이콘화**: [편집], [삭제] 텍스트 버튼을 `Lucide Icon` (Edit3, Trash2 등)으로 변경하여 공간 절약 및 시각적 정돈.

#### 🔢 세그먼트 및 랭킹 페이지

* **문제점**: 큰 폰트 크기와 넓은 여백으로 인해 정보 밀도가 낮음.
* **개선안**:
    1. **Metrics Bar 축소**: 상단 요약 카드의 높이를 `h-24`로 줄이고, 폰트 크기를 `text-2xl`로 조정.
    2. **검색 바 통합**: 상단 헤더 옆이나 테이블 상단 우측으로 검색 바를 이동하여 수직 공간 절약.

#### 🏆 외부 랭킹 페이지 (External Ranking)

* **현황 진단 (스크린샷)**:
  * **Search Bar Waste**: 검색 영역의 배경 박스(`p-6` 추정)가 불필요하게 크고 두꺼움.
  * **Inline Input Clutter**: 'Deposit', 'Plays' 컬럼이 입력 창 형태(Input Box)로 되어 있어 데이터처럼 보이지 않고 시각적으로 부담스러움.
  * **Badge Line-break**: 'Verified' 뱃지가 ID 밑으로 줄바꿈되어 행 높이를 2배로 늘리고 있음.
* **개선안**:
    1. **Transparent Search Bar**: 컨테이너 배경을 제거하고, 심플한 라인이나 투명 배경의 검색 바로 변경하여 상단 여백 최소화.
    2. **Read-Only Data Display**:
        * Deposit/Plays 값을 입력창에서 **순수 텍스트(Text)**로 변경.
        * `text-right font-mono tabular-nums` 적용하여 깔끔한 숫자 데이터로 표현.
    3. **One-Line Row**: 'Verified' 뱃지를 ID 옆(`flex gap-2`)으로 배치하여 행 높이를 줄임.
    4. **Action Icon**: 삭제(Trash) 버튼을 `text-zinc-500 hover:text-rose-500` 아이콘으로 심플하게 처리.
