# 게임 관리 레이아웃 디자인 가이드라인 (ISFJ Edition)

## 👤 타겟 페르소나 분석 (ISFJ 관리자)

* **성향**: 논리적이고 체계적이지만, 눈에 보이지 않는 확률이나 수치에 대해 불안감을 느낌. "이게 정말 10%가 맞나?"
* **Pain Point**: 텍스트로만 적힌 확률 설정. 설정 후 실제 게임에서 어떻게 보일지 상상이 안 됨.
* **Design Goal**: **"Visible, Tangible, Verified"** (눈에 보이고, 실체적이며, 검증된).

---

## 1. 핵심 디자인 코드: "Visual Probability & Preview"

### A. 확률 시각화 (Probability Bar)

숫자(%)만으로는 감이 오지 않습니다.

* **Progress Bar UI**: 확률을 길이로 표현하는 바(Bar)를 도입합니다.
* **Color Coding**: 등급별로 색상을 지정하여 "어떤 등급이 많은지" 색감으로 느끼게 합니다.
  * `Common (일반)`: Zinc-500 (회색)
  * `Uncommon (고급)`: Cyan-400 (하늘색)
  * `Rare (희귀)`: Emerald-400 (녹색)
  * `Epic (영웅)`: Amber-400 (황금색)
  * `Legendary (전설)`: Fuschia-400 (자주색)
  * *규칙: 위 색상은 전역(`index.css`) 변수로 관리.*

### B. 라이브 포커스 (Live Focus)

현재 유저들이 플레이 중인 게임 설정이 무엇인지 0.1초 만에 알 수 있어야 합니다.

* **Active Glow**: 활성 상태인 설정 행(Row) 전체에 `ring-1 ring-brand bg-brand/5` 효과 적용.
* **On/Off Switch**: 텍스트 상태값 대신 직관적인 **Toggle Switch** 사용. (단, Off 시에는 빨간색 경고 모달).

---

## 2. 게임 관리 페이지 상세 가이드

### 🎡 룰렛 설정 (Roulette)

**"돌아가는 판을 눈으로 확인."**

1. **세그먼트 스트라이프 (Color Stripe)**
    * 테이블 내 '세그먼트' 컬럼에 `[빨][파][초][노]...` 형태의 **색상 띠**를 표시.
    * 설정된 보상 등급 배열을 시각적으로 미리 보여줌.

2. **확률 분포 그래프**
    * 설정 상세 진입 시, 상단에 **"당첨 확률 분포도"** (가로 막대 그래프) 배치.
    * "꽝 20%, 100원 50%, ..." 한눈에 파악 가능.

### 🎲 주사위 설정 (Dice)

**"승률의 투명성."**

1. **리스트 뷰 전환**
    * 기존의 대시보드 형태를 버리고, **"설정 목록(List)"** 형태로 변경하여 여러 버전을 관리하기 쉽게 함.
    * 각 버전별 `RTP(환수율)`을 자동 계산하여 우측에 표시. (예: `RTP: 92.5%` - 안전함/위험함 색상 표시).

2. **보상 아이콘**
    * 승리/무승부/패배 보상에 텍스트(`TOKEN`) 대신 **토큰 아이콘** 사용.

### 🎫 복권 설정 (Lottery)

**"상품 진열장."**

1. **상품 쉘프 (Prize Shelf)**
    * 테이블 내에 '상품 목록'을 텍스트로 나열하지 않고, **아이콘 3~4개**를 가로로 나열.
    * 1등 상품(가장 비싼 것)에는 왕관(👑) 뱃지 부착.

2. **판매 미니 차트**
    * 해당 회차의 판매 추이를 보여주는 **Sparkline (미니 선 그래프)** 추가.
    * 관리자가 "이 회차는 인기가 없네?" 등으로 직관적 판단 가능.

## 3. 구현 체크리스트 (Visual Check)

* [ ] 확률(%)이 텍스트뿐만 아니라 **색상 바**로도 표현되는가?
* [ ] 현재 활성화(Active)된 설정이 다른 비활성 설정보다 **확실히 눈에 띄는가**?
* [ ] 보상 아이템들이 텍스트가 아닌 **아이콘**으로 보여지는가?
* [ ] 위험한 설정(확률 100% 등)에 대한 **경고 표시**가 있는가?

## 4. 2차 리팩토링 계획 (Secondary Refactoring Plan)

특히 **금고 관리(Vault)** 페이지에 대한 사용자의 *"레이아웃 전면 교체"* 요구를 수용하여, 단순한 리스트 나열이 아닌 **"자산 통제 센터(Asset Control Center)"** 컨셉으로 재설계합니다.

### A. 금고 관리 전면 개편 (Vault Page Overhaul)

* **배경**: 현재는 여러 기능(요약, 요청목록, 탑랭커, 제어판)이 세로로 길게 나열되어 있어 한눈에 현황 파악이 어려움.
* **컨셉**: **"Dashboard Grid Layout"**
  * 화면을 2x2 또는 비대칭 그리드로 분할하여 스크롤 없이 주요 정보를 한 번에 모니터링.

#### Layout Structure (Grid System)

1. **Row 1: KPI Tickers (상단 띠)**
    * `오늘의 적립`, `총 부채(Liability)`, `출금 대기금`을 얇은 상단 바(Ticker) 형태로 지속 노출.
    * 기존의 큰 카드 형태를 압축하여 공간 효율화.

2. **Row 2: Main Control (좌측) + Golden Hour (우측)**
    * **좌측 (70%)**: [출금 요청 처리] 테이블.
        * 투박한 테이블 대신 **"요청 카드 리스트"** 또는 **"Compact Table"** 사용.
        * 승인/반려 버튼을 아이콘화하여 심플하게 배치.
    * **우측 (30%)**: [골든 아워 컨트롤].
        * 거대한 버튼 대신 **세련된 토글/슬라이더 UI**.
        * "현재 상태: ON/OFF"를 명확한 신호등(Green/Red Dot)으로 표시.

3. **Row 3: Risk Monitoring (하단)**
    * [상위 적립 유저]와 [리스크 레이더]를 하단에 배치하여 특이사항 발생 시에만 주목하도록 함.

### B. 게임 설정 페이지 공통 개선

1. **Compact Config Mode**
    * 룰렛/주사위 등의 설정 패널이 화면을 너무 많이 차지함.
    * **"설정값 요약 뷰"**를 기본으로 보여주고, 클릭 시 수정 패널이 확장(Expand)되거나 모달이 뜨는 방식 적용.
2. **Visual Fonts**
    * 게임 확률표의 숫자(`98.5%`)를 `font-mono text-lg font-bold text-emerald-400` 등으로 강조.
    * 텍스트 라벨은 작고 흐리게(`text-xs text-zinc-500`) 처리하여 숫자 데이터 자체를 돋보이게 함.
