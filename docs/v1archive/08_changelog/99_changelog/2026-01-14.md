- 어드민 상점 오버라이드가 문자열 숫자로 저장돼도 상품이 무시되지 않도록 백엔드 파싱 로직을 보강했다.

## 변경사항

### 1) ShopService: UI Config 오버라이드 파싱 강화
- `cost_amount`, `item_amount`, `is_active`가 문자열/float로 저장된 경우에도 정상 반영.
- `cost_token` 문자열은 대소문자/공백을 정규화해 매칭.
- 결과적으로 어드민 상점에서 만든/수정한 상품이 `/api/shop/products`에 정상 노출.
- 관련 파일: `app/services/shop_service.py`

### 2) UserInventoryModal: 아이템 코드 드롭다운 연동
- 보유 아이템 + reward-types 기반 아이템 코드 선택 드롭다운 추가.
- 직접 입력 모드 제공, 문구/레이블 정리.
- 인벤토리 조정/조회 API는 numeric id 또는 identifier 모두 처리.
- 관련 파일: `src/admin/components/UserInventoryModal.tsx`

### 3) VaultControlPanel: 탭 라벨 깨짐 복구
- 규칙/UI/잔액 탭 텍스트를 정상 한글로 복구.
- 관련 파일: `src/admin/components/vault/VaultControlPanel.tsx`
