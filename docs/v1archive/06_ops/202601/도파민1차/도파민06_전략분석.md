## 🔥 핵심 문제 정의

> **사용자 질문**: "너무 퍼줄 수만은 없다. 외부사이트 이용도 안하는 새끼들한테 다 퍼줄 수는 없잖아. 지금 머리가 아픈거야. 진짜 리텐션 효과가 있을지 전략적으로 검토해줘."

### 현재 상황

| 항목 | 현황 |
|:---|:---|
| **기본 룰렛 RTP** | ~80% |
| **주사위 RTP** | **7.5%** (Broken) |
| **골드/다이아 룰렛** | 120-150% (유저 유리) |
| **신규유저 혜택** | 금고 2,000P + 티켓 5장 (무조건 지급) |
| **VIP 패스트트랙** | 50만원 입금 → +500 XP (무조건 지급) |

### 사업 리스크

1. **골드/다이아 룰렛 RTP 150%** → 사이트가 돈을 퍼주는 구조
2. **외부사이트 이용 안하는 유저**에게도 동일 혜택 → ROI 없음
3. **체리피커** (10~20만 작업장) 필터링 안됨 → 손실만 발생

## 💡 전략적 분석 결과 (수정)

### 🎯 진짜 목표 재정의

> [!IMPORTANT]
> **착각했던 것**: 외부 수수료 수익 모델  
> **진짜 목표**: **COMMON 유저를 외부사이트 이용자로 전환**

이 프로젝트는 **외부사이트 마케팅 비용**입니다.  
목표는 "여기서 재미봤으니 진짜 돈 넣어서 해볼까?" 유도하는 것.

### ❌ 현재 전략의 문제점

| 문제 | 설명 | 영향 |

## 📈 예상 효과 (마케팅 비용 관점)

> [!NOTE]
> **수정된 ROI 모델**: 외부 수수료 수익이 아닌, **외부사이트 전환율**이 성공지표  
> **현실적 규모**: 일 가입자 15명 기준

### Before (현재)

| 항목 | 값 |
|:---|:---|
| 일 가입자 | **15명** |
| 신규 지급 비용 | 15명 × 2,000P = **30,000P** |
| 골드룰렛 손실 (무차별) | 8회 × 10,000P = **80,000P** |
| **일 총 비용 (마케팅)** | **-110,000P** 💀 |
| 외부사이트 전환 | **1명 (6.7%)** ❌ 매우 비효율 |
| **전환당 비용** | 110,000P ÷ 1명 = **110,000P/명** 💸 |

### After (개선)

| 항목 | 값 |
|:---|:---|
| 일 가입자 | **15명** |
| COMMON (12명) | 12명 × 2,000P = **24,000P** |
| VIP (2명) | 2명 × 10,000P (골드3회) = **20,000P** |
| WHALE (1명) | 1명 × 10,000P = **10,000P** |
| 전환 보너스 | 3명 × 5,000P = **15,000P** |
| **일 총 비용 (마케팅)** | **-69,000P** ✅ |
| **절감 효과** | **-41,000P (-37%)** |
| 외부사이트 전환 | **3명 (20%)** ✅ 3배 개선 |
| **전환당 비용** | 69,000P ÷ 3명 = **23,000P/명** 🎯 |

**핵심 성과**:
- 예산: 110,000P → 69,000P (**-37% 절감**)
- 전환율: 6.7% → 20% (**+200% 개선**)
- 전환당 비용: 110,000P → 23,000P (**-79% 효율화**)

**월간 예산 (30일)**:
- Before: 330만P (전환 30명)
- After: 207만P (전환 90명) → **-123만P 절감 + 60명 추가 전환**
