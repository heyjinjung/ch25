# 📊 통합 리텐션 전략 분석 보고서 (v1.1)

## 1. 목적 (Purpose)
현행 운영 시스템(웰컴 미션, 스트릭 등)과 실제 유저 행동 데이터 간의 간극을 진단하고, 이를 메우기 위한 데이터 기반의 리텐션 강화 전략을 수립합니다.

## 2. 범위 (Scope)
VIP 그룹 관리, 이탈 위험군(Growth) 케어, 어뷰저(Efficiency) 필터링 전략 및 기술적 구현 가이드를 포함합니다.

## 3. 용어 정의 (Definitions)
- **손실 회피(Loss Aversion)**: 유저가 이미 획득한 이익(금고 잔액 등)을 잃지 않으려 하는 심리 기제.
- **레벨 점프(Level Jump)**: XP 축적 과정을 생략하고 즉시 상위 레벨로 도달하게 하는 보상 체계.

## 4. 본문

### ## 1) 데이터 기반 현황 진단
| 구분 | 현상 | 기회 요인 |
| :--- | :--- | :--- |
| **Welcome** | Day 2 이탈률 높음 | Day 1에서 Day 2 보상을 '예약'하는 확정형 액션 필요 |
| **Streak** | 저레벨 정체 구간 존재 | 3일 달성 시 '레벨 점프'로 고가치 구간 강제 진입 |
| **Nudge** | 단순 알람의 클릭률 저하 | 금고 잔액 등 개인화 테이터를 인용한 '리콜' 메시지 필요 |

### ## 2) 핵심 전략 믹스 (Mix)
1)  **[Growth] Day 2 보상 예약**: 미션 완료 시 '내일의 보상'을 예약하게 하여 재방문 약속 유도.
2)  **[Growth] 스트릭 레벨 점프**: 3~5레벨 정체 유저를 레벨 점프로 상위 컨텐츠에 안착시킴.
3)  **[CRM] 개인화 넛지**: 금고에 방치된 잔액 정보를 활용해 손실 회피 심리 자극.

### ## 3) 운영 리스크 방어
- **출금 게이트**: 웰컴 보상 회수 후 즉시 출금 방지를 위해 '누적 충전' 또는 '판수' 조건 강화.
- **다이나믹 부스트**: 어뷰저 태그 유저는 금고 적립 배수를 실시간으로 하향(0.5x) 조정.
