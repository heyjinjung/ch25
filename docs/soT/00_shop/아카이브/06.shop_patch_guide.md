## 🔴 1. Strict Vault Policy (제재) 미적용 패치 가이드

**이슈**: `benefits_suspended=True` (7일 미입금) 상태인 유저에 대해 상점 구매 차단 로직이 누락됨.

### [1단계] 코드 수정

#### 1.1 Service Layer 수정
- **파일**: `app/v2/services/shop_service.py`
- **수정 내용**: `purchase` 메서드 시작 지점에 `benefits_suspended` 체크 로직 추가.

```python
# app/v2/services/shop_service.py

from app.services.vault_service import VaultService  # VaultService 임포트 필요

class V2ShopService:
    @staticmethod
    def purchase(db: Session, *, user_id: int, ...):
        # [추가] Strict Vault Policy 체크
        from app.models.user import User
        legacy_user = db.get(User, user_id)
        if legacy_user:
            policy = VaultService.get_user_vault_policy(db, legacy_user, datetime.utcnow())
            if policy.get("benefits_suspended"):
                raise ValueError("BENEFITS_SUSPENDED") # 또는 전용 Exception
        
        # ... 기존 로직 ...
```

#### 1.2 API Route 수정
- **파일**: `app/v2/api/routes.py`
- **수정 내용**: `purchase_shop_product` 엔드포인트에서 예외 처리 추가.

```python
# app/v2/api/routes.py

@router.post("/shop/purchase", ...)
def purchase_shop_product(...):
    try:
        # ... 기존 로직 ...
        order = V2ShopService.purchase(...)
        # ...
    except ValueError as exc:
        if str(exc) == "BENEFITS_SUSPENDED":
            raise HTTPException(status_code=403, detail="BENEFITS_SUSPENDED_7D_NO_DEPOSIT")
        raise HTTPException(status_code=400, detail=str(exc))
```
