# 변경 로그: 운영일(09:00 KST) 기준 미션 활성/필터 정렬

**날짜**: 2026-02-14  \
**작성자**: GitHub Copilot  \
**관련 도메인**: Mission / Events (valentine-seol)

## 변경 배경
- 운영일(Asia/Seoul, 09:00 리셋) 기준과 캘린더 데이(00:00) 기준이 혼재하면, 특정 미션이 다음 운영일에도 진행도 업데이트되거나 노출되는 문제가 발생할 수 있다.
- 이벤트 상태 API가 “현재 운영일” 기준으로 미션을 내려주지 않으면, FE/BE가 서로 다른 기준으로 필터링할 가능성이 커진다.

## 변경 내용 (정책/구현 정렬)
### 1) 미션 활성 판정 기준 통일
- 활성(노출/진행/클레임 대상) 판정은 **운영일(09:00 KST 리셋)** 기준으로 수행한다.
- `start_date/end_date`는 운영일 구간과의 **overlap(겹침) 조건**으로 판정하여 경계값(예: `end_date=23:59:59`)에 흔들리지 않도록 한다.

### 2) 이벤트 상태 API 운영일 필터 적용
- `GET /api/events/valentine-seol/status`는 **현재 운영일에 해당하는 이벤트 미션만** 반환한다.
- 이벤트 미션 필터 역시 운영일 구간 overlap 조건으로 적용한다.

## 영향 범위
- 운영일 경계(자정~09:00 KST)에서 미션 노출/진행도 업데이트의 예측 가능성이 증가한다.
- FE가 별도 운영일 필터를 구현하지 않아도, API 레벨에서 “현재 운영일”만 내려주므로 정합성이 강화된다.
