## 3. 핵심 기능 3가지

### 3.1 기능 1: 자동 세그먼트 분류

```python
def _classify_segment(row: Dict) -> str:
    margin = parse_int(row.get('총 운영 마진', 0))
    inactive_days = parse_int(row.get('미접속 경과일', 0))
    charge_amount = parse_int(row.get('누적 충전 금액', 0))

    if margin > 1_000_000:                    # 마진 100만원 초과
        return 'VIP'
    elif inactive_days > 7 and margin > 0:   # 7일 이상 미접속 + 마진 양수
        return 'AT_RISK'
    elif charge_amount > 5_000_000:          # 충전 500만원 초과
        return 'WHALE'
    else:
        return 'COMMON'
```

#### 세그먼트별 골든 전략
| 세그먼트 | 조건 | 골든 전략 |
|---------|------|----------|
| **VIP** | 마진 100만원+ | 고배율 골든아워, 우선 지원 |
| **WHALE** | 충전 500만원+ | VIP 전환 유도 |
| **AT_RISK** | 7일+ 미접속 + 마진 양수 | 자동 리워드, 복귀 캠페인 |
| **COMMON** | 기본 | 일반 운영 |

### 3.2 기능 2: V2User 매칭 및 잠재고객 관리

#### 매칭 프로세스
```
CSV 데이터
    ↓
1. V2User 매칭 시도 (cc_id 또는 nickname)
    ↓
├── 매칭 성공 → V2UserSegment 업데이트/생성
│
└── 매칭 실패 → HQProspectiveUser 테이블에 저장 (잠재 고객)
```

#### 잠재고객 테이블 (`hq_prospective_user`)
| 필드 | 타입 | 설명 |
|------|------|------|
| `cc_id` | VARCHAR | 본사 식별자 |
| `nickname` | VARCHAR | 가입 시 매칭 키 |
| `total_margin` | BIGINT | 총 마진 |
| `total_charge` | BIGINT | 총 충전액 |
| `segment` | VARCHAR | 분류된 등급 |
| `is_joined` | BOOLEAN | V2 가입 여부 |

## 6. 붙여넣기 Import (2026-02-04 추가)

> CSV 파일 업로드 없이 **클립보드 붙여넣기**로 데이터를 Import합니다.

### 6.1 지원 형식
| 타입 | 컬럼 형식 | 용도 |
|------|----------|------|
| `DAILY_DEPOSIT` | 번호/소속/이름/닉네임/신청날짜/충전금액/입금자명/충전날짜/상태 | 입금 → 레벨 → 보상 |
| `GAME_LOG` | 번호/이름/닉네임/타입/베팅일시/게임종류/금액 | 수익률 분석, 위기 감지 |

### 6.2 시간 기반 필터링
- DB에 기록된 **최신 시간 이후의 데이터만** 처리
- 중복 Import 방지

### 6.3 API 엔드포인트
- `POST /api/v2/admin/csv-import/paste-import` - 실제 Import
- `POST /api/v2/admin/csv-import/paste-import/preview` - 미리보기

### 6.4 데이터 흐름
```
[DAILY_DEPOSIT]
붙여넣기 → PasteImportService → HQDailyDepositLog 저장
         → CCDepositService.upsert_many()
         → v2_user.total_charge_amount 업데이트 (V2 SoT)
         → external_ranking_data 동기화
         → 레벨 시스템 트리거

[GAME_LOG]
붙여넣기 → PasteImportService → V2GameLog 저장
         → GameLogAnalyticsService → 수익률/위기 분석
         → OpsDashboard 반영
```
