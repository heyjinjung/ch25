### G. 출석(로그인) 미션 카운트 누락 (V2 Auth 트리거) ✅
- 우선순위: 높음
- 증상:
  - 출석/로그인 미션이 `0/1`에서 증가하지 않아 Claim이 열리지 않음
  - 특히 V2 로그인(`POST /api/v2/auth/token`)만 사용하는 환경에서 재현 가능
- Root Cause:
  - 레거시 로그인 경로는 로그인 시점에 `MissionService.ensure_login_progress(user.id)`를 호출하지만,
    V2 로그인/토큰 발급 경로는 이를 호출하지 않으면 `action_type=LOGIN` 미션 progress가 생성/증가하지 않음
- Allowed Files:
  - `app/v2/api/auth_routes.py`
  - `app/v2/api/dev_login.py` (로컬/개발 로그인도 동일 처리 권장)
  - (회귀 테스트) `tests/v2_tests/phase5_public/test_v2_mission_extended.py`
- 단계별 작업:
  1. V2 토큰 발급 성공 후 `master_user_id = V2UserService.ensure_legacy_user_id(...)`로 legacy user_id 확보
  2. best-effort로 `MissionService(db).ensure_login_progress(master_user_id)` 호출(실패해도 로그인 자체는 막지 않음)
  3. 회귀 테스트로 “V2 로그인 → LOGIN 미션 progress +1”을 고정
- Verify 항목:
  - V2 로그인 후 `GET /api/v2/mission/`에서 출석/로그인 미션 progress가 +1 반영
  - pytest: `tests/v2_tests/phase5_public/test_v2_mission_extended.py` 통과
