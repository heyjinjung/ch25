## 1. 목적
- V2 상점 구매 성공(200 OK) 후 금고 잔액이 UI에 즉시 반영되지 않던 문제를 해결하고, 원인/수정/검증 방법을 기록한다.

## 2. 범위
- 포함: V2 Shop 구매 훅의 react-query 캐시 무효화(invalidate) 키 정합성
- 제외: 금고 SoT 변경, 상점 차감 로직 변경, UI 디자인 변경

## 3. 문제 요약
- 현상: `POST /api/v2/shop/purchase`는 200 OK로 성공하고 아이템은 인벤토리에 정상 적재되나, 유저 화면(헤더/금고 표시)의 금고 잔액이 즉시 감소하지 않음.

## 4. 근본 원인(RCA)
- 프론트의 상점 구매 성공 후 캐시 무효화 키가 실제 사용 중인 키와 불일치함.
  - 실제 금고 상태 쿼리 키: `['v2-vault-status']`
  - 기존 코드 무효화 키: `['vault-status']` (존재하지 않는 키)
- 결과: 구매 직후에도 금고 상태 쿼리가 재호출되지 않아, staleTime/refetch 주기 동안 이전 잔액이 유지되어 “차감이 안 된 것처럼” 보임.

## 5. 해결 내용
- 상점 구매 성공(`useV2PurchaseProduct.onSuccess`)에서 무효화 키를 실제 사용 중인 키로 수정.
  - `['vault-status']` → `['v2-vault-status']`
  - `['user-status']` → `['v2-user-me']` (일관성 보강)
