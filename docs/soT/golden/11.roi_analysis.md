# 11. ROI Analysis (Campaign Performance)

## 1. 개요 (Overview)
**ROI Analysis**는 골든 시스템의 핵심 요소인 "Intervention(개입)"의 효율성을 측정하는 도구입니다.
시스템이 유저에게 제공한 혜택(Reward Cost) 대비, 해당 유저가 창출한 가치(Predicted LTV)를 비교하여 각 캠페인(이벤트/트리거)의 성과를 분석합니다.

> [!NOTE]
> **Acquisition ROI vs Retention ROI**
> - **Acquisition ROI (채널 성과)**: 외부 광고비 대비 유입 성과 (Analytics Dashboard 내 "Marketing Efficiency" 탭)
> - **Retention ROI (캠페인 성과)**: 내부 개입(Intervention) 비용 대비 유저 잔존/매출 성과 (본 문서의 범위)

## 2. 핵심 로직 (Core Logic)

### 2.1. 데이터 소스
- **V2RetentionRoiLog**: 개입 시점에 `V2RetentionInterventionService`가 생성하는 로그.
    - `marketing_cost`: 지급된 보상(Reward)의 가치 (KRW 환산).
    - `predicted_ltv`: 개입 시점의 유저 예측 LTV.
    - `roi_percent`: `(predicted_ltv / marketing_cost) * 100`.
    - `event_type`: 개입 트리거 (예: `LOSS_STREAK`, `SESSION_END`).

### 2.2. 집계 방식 (Aggregation)
`V2RoiAnalysisService`는 `V2RetentionRoiLog`를 기반으로 다음 지표를 집계합니다.
- **User Count**: 해당 캠페인에 노출된 고유 유저 수.
- **Total Cost**: 총 마케팅 비용 (보상 합계).
- **Total Return**: 총 회수 가치 (예측 LTV 합계).
- **Avg ROI**: 평균 ROI 퍼센트.

## 3. 골든 시스템과의 연계 (Golden Alignment)
본 기능은 골든의 "Evidence-based Operations" 원칙을 따릅니다.
- **근거(Evidence)**: 모든 개입은 `predicted_ltv`라는 근거를 기반으로 수행됩니다.
- **피드백(Feedback)**: ROI 분석 결과는 `SEGMENT_BASE_RATE` 조정이나 개입 정책 수정의 근거로 활용됩니다.
- **위치(Location)**: `AnalyticsDashboard`의 "마케팅 효율성" 탭에 위치하여, 전체적인 마케팅 성과(Acquisition + Retention)를 통합적으로 조망할 수 있도록 합니다.
