## 🟡 3. 기프티콘 네이밍 정규식 검증 가이드

**이슈**: `{BRAND}_GIFTICON_{AMOUNT}` 포맷 준수 여부 불분명.

### [1단계] DB 전수 조사 쿼리
실제 DB에 저장된 데이터 중 규칙을 벗어난 항목을 식별합니다.

```sql
-- 1. 정규식 포맷에 맞지 않는 데이터 조회 (MySQL 기준)
SELECT * FROM user_inventory_item 
WHERE item_type LIKE '%_GIFTICON_%'
AND item_type NOT REGEXP '^[A-Z0-9]+_GIFTICON_[0-9]+$';

-- 2. 소문자가 포함된 데이터 조회
SELECT * FROM user_inventory_item 
WHERE item_type LIKE '%_GIFTICON_%' 
AND BINARY item_type REGEXP '[a-z]';
```
