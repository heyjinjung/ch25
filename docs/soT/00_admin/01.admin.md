## 4. 중학생도 이해하는 정합성 충돌 해설 (쉽게 풀어서 읽기)

> 정정(2026-02-06): 아래 3개 항목은 과거에 발견된 대표 이슈를 이해하기 위한 설명이며, 현재 코드/라우트 기준으로는 **해결 완료** 상태이다.

지금 어드민(관리자) 시스템에서 발견된 3가지 큰 문제점을 일상생활에 비유해서 설명해줄게!

### 1️⃣ "어제와 오늘의 기준이 달라요!" (리셋 시간 불일치)
- **현재 상태**: ✅ 해결됨 (운영일 경계 09:00 KST 헬퍼로 통일)
- **무슨 기능인가요?**: 유저가 며칠 연속으로 게임을 했는지 세는 '스트릭'과, 관리자가 오늘 얼마나 벌었는지 보는 '대시보드'예요.
- **무슨 일을 하나요?**: 스트릭은 매일 아침 9시에 "오늘 시작!"이라고 외치고, 대시보드는 밤 12시가 되자마자 "오늘 시작!"이라고 외쳐요.
- **왜 문제인가요?**: 예를 들어, 밤 1시에 게임을 하면 대시보드에서는 '오늘' 한 게임인데, 스트릭은 아직 '어제'라고 생각해요. 서로 '오늘'에 대한 기준이 달라서 통계가 뒤죽박죽될 수 있어요. 
- *비유: 학교는 9시에 시작하는데, 출석부는 밤 12시에 미리 채워놓는 상황이랑 비슷해요!*

### 2️⃣ "안전장치가 서류에만 있고 기계에는 없어요!" (서킷 브레이커 누락)
- **현재 상태**: ✅ 해결됨 (서킷 브레이커 서비스 + 어드민 제어 API 제공)
- **무슨 기능인가요?**: 너무 많은 돈(게임 포인트)이 한꺼번에 빠져나가지 못하게 막는 '안전 밸브'예요.
- **무슨 일을 하나요?**: "한 시간에 1,000만 원 넘게 나가면 일단 멈춰!"라고 규칙서(SOT)에 써놓았어요.
- **왜 문제인가요?**: 규칙서에는 써놨는데, 정작 프로그램을 짤 때(코딩할 때) 이 기능을 안 넣었어요. 누군가 나쁜 마음을 먹고 돈을 왕창 빼가도 기계가 자동으로 멈추질 않아요.
- *비유: '과자 정해진 만큼만 먹기'라고 규칙은 정했는데, 과자 상자 자물쇠를 안 잠가둔 것과 같아요!*

### 3️⃣ "게임은 시작했는데 심판이 도구가 없어요!" (팀배틀 관리 도구 부재)
- **현재 상태**: ✅ 해결됨 (V2 팀배틀 어드민 API/서비스 레이어 구현)
- **무슨 기능인가요?**: 팀을 나눠서 싸우는 '팀배틀'을 관리자가 관리하는 화면이에요.
- **무슨 일을 하나요?**: "이번 시즌 시작!", "이 팀이 이겼으니까 상금 줘!" 같은 걸 버튼 하나로 해야 해요.
- **왜 문제인가요?**: 데이터베이스(창고)에는 팀배틀 자리를 다 만들어놨는데, 정작 관리자가 쓸 수 있는 버튼이나 화면이 없어요. 지금은 관리자가 직접 창고에 들어가서 손으로 수정해야 하는 위험한 상태예요.
- *비유: 축구 시합은 하고 있는데, 심판한테 호각도 없고 점수판도 없는 상황이에요!*
