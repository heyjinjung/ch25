## 1. 목적
SEO SoT에 따라 대외 공개 웹의 구글 검색 반영을 단계적으로 달성하기 위한 실행 계획을 정의한다.

## 2. 범위
- 대상: 랜딩 페이지 1종 + 공개 블로그/뉴스 페이지(선택)
- 측정: 로그 기반 지표

## 3. 단계별 계획
### 3.1 1단계: 기준 확정 (SoT 수립)
- 산출물: SEO SoT 문서, QA 체크리스트 초안
- 완료 기준: SoT 승인 및 변경로그 등록

### 3.2 2단계: 현황 진단 (베이스라인)
- 로그 기반 크롤링/인덱싱 현황 요약
- 200/301/404 분포, 응답시간 상위 URL 분석
- 산출물: 베이스라인 리포트, 개선 백로그

### 3.3 3단계: 랜딩 페이지 설계
- 랜딩 1페이지의 정보 구조/키메시지/CTA 확정
- 메타/OG/Twitter/캐노니컬/구조화 데이터 초안 작성
- 산출물: 랜딩 페이지 콘텐츠 스펙

### 3.4 4단계: 기술 SEO 적용
- 사이트맵/robots 정책 확정
- 메타/구조화 데이터 반영
- 성능 개선 작업(이미지/폰트/스크립트)
- 산출물: 기술 반영 체크리스트

### 3.5 5단계: 검증 및 론칭
- 로그 기반 크롤러 유입 확인
- 200/404 비율, 응답시간 기준 만족 확인
- 산출물: 론칭 검증 리포트

### 3.6 6단계: 운영 루틴
- 주간 리포트: 인덱싱 대상, 크롤러 방문, 에러 비율
- 월간 리포트: 트렌드 변화, 주요 개선점
- 산출물: 운영 템플릿

## 4. 우선순위
1) 랜딩 페이지 1종의 구글 검색 반영
2) 로그 기반 크롤러 지표 안정화
3) 블로그/뉴스 콘텐츠 템플릿 확장

## 5. 리스크 및 대응
- 인덱싱 지연: 사이트맵 갱신 주기 및 크롤러 접근성 재점검
- 중복 페이지: 캐노니컬 정책 강화
- 성능 저하: 핵심 웹 바이탈 개선 우선 적용
