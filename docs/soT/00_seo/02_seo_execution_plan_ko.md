상태: SoT

## 1. 목적
SEO SoT에 따라 대외 공개 웹의 구글 검색 반영을 단계적으로 달성하기 위한 실행 계획을 정의한다.

## 2. 범위
- 대상: 랜딩 페이지 1종 + 공개 블로그/뉴스 페이지(선택)
- 측정: 로그 기반 지표

## 3. 단계별 계획
### 3.1 1단계: 기준 확정 (SoT 수립)
- 산출물: SEO SoT 문서, QA 체크리스트 초안
- 완료 기준: SoT 승인 및 변경로그 등록

### 3.2 2단계: 현황 진단 (베이스라인)
- 로그 기반 크롤링/인덱싱 현황 요약
- 200/301/404 분포, 응답시간 상위 URL 분석
- 산출물: 베이스라인 리포트, 개선 백로그

### 3.2.1 2.5단계: 키워드/랜딩 URL 확정 (타깃 고정)
- 목표 키워드: `씨씨카지노`, `씨씨 카지노`, `씨씨지민`
- 핵심 랜딩 URL: `https://cc-jm.com/` (루트)
	- 이유: 브랜드/서비스명(씨씨카지노) 의도에 대한 대표 엔트리로 고정하고, 모든 내부 링크/캐노니컬을 루트로 수렴시킨다.
	- 주의: 앱(로그인/세션 의존) 라우트는 검색 노출 대상이 아니므로, 랜딩과 앱 라우트를 분리 운영한다.
- 산출물: 타깃 키워드-페이지 매핑표, 랜딩 URL/캐노니컬 확정

### 3.3 3단계: 랜딩 페이지 설계
- 랜딩 1페이지의 정보 구조/키메시지/CTA 확정
- 메타/OG/Twitter/캐노니컬/구조화 데이터 초안 작성
- 산출물: 랜딩 페이지 콘텐츠 스펙

### 3.4 4단계: 기술 SEO 적용
- 사이트맵/robots 정책 확정
- 메타/구조화 데이터 반영
- 성능 개선 작업(이미지/폰트/스크립트)
- 산출물: 기술 반영 체크리스트

### 3.4.1 4.5단계: Google Search Console 운영 세팅 (인덱싱 0→1)
- 소유권 확인(권장: DNS TXT)
- 사이트맵 제출
- URL 검사(랜딩 루트) 및 색인 생성 요청
- 색인 커버리지(제외/오류) 확인 및 원인 제거
- 산출물: GSC 세팅 완료 증빙(스크린샷/체크리스트), 초기 인덱싱 확인 리포트

### 3.5 5단계: 검증 및 론칭
- 로그 기반 크롤러 유입 확인
- 200/404 비율, 응답시간 기준 만족 확인
- 산출물: 론칭 검증 리포트

### 3.6 6단계: 운영 루틴
- 주간 리포트: 인덱싱 대상, 크롤러 방문, 에러 비율
- 월간 리포트: 트렌드 변화, 주요 개선점
- 산출물: 운영 템플릿

## 4. 우선순위
1) 랜딩 페이지 1종의 구글 검색 반영
2) 로그 기반 크롤러 지표 안정화
3) 블로그/뉴스 콘텐츠 템플릿 확장

## 4.1 키워드 목표(운영 목표)
- 1차: `씨씨카지노`, `씨씨 카지노` (브랜드/서비스명 변형 포함)
- 2차: `씨씨지민` (의도 정의가 선행되어야 하며, 의도가 랜딩과 다르면 별도 페이지로 분리)

## 5. 리스크 및 대응
- 인덱싱 지연: 사이트맵 갱신 주기 및 크롤러 접근성 재점검
- 중복 페이지: 캐노니컬 정책 강화
- 성능 저하: 핵심 웹 바이탈 개선 우선 적용

## 5.1 리스크 추가 (키워드 상위권 관점)
- 의도 불일치: `씨씨지민`의 검색 의도가 인물/별칭/별도 엔티티일 경우, 랜딩 1페이지로 커버하면 반송/체류지표 악화 리스크가 있으므로 분리 여부를 판단한다.
- 브랜드 신뢰 부족: 인덱싱 0 상태에서는 기술 적용만으로 상위권이 어렵다. GSC로 인덱싱 안정화 후, 외부 언급/링크(브랜드 신뢰 신호) 확보 작업을 병행한다.
