## 1. 목적
구글 검색 반영을 목표로 하는 핵심 랜딩 페이지 1종의 콘텐츠/IA/메타 기준을 정의한다.

## 2. 범위
- 대상: 대외 공개 랜딩 페이지 1종
- 제외: 로그인 이후 페이지, 내부 운영 페이지

## 2.1 타깃 키워드 (운영 목표)
- 1차: `씨씨카지노`, `씨씨 카지노`
- 2차: `씨씨지민` (의도 정의가 선행되어야 하며, 랜딩 의도와 다르면 별도 페이지 분리)

## 2.2 랜딩 URL 원칙
- 대표 랜딩 URL: `https://cc-jm.com/`
- Canonical은 반드시 루트로 고정한다.

## 3. 정보 구조(IA)
1) 헤더
- 로고
- 1차 CTA 버튼

2) 히어로 섹션
- H1 (핵심 가치 제안 1문장)
- 서브 카피 (문제-해결-성과)
- 1차 CTA
- 보조 신뢰 요소(로고/수치/리뷰 중 1개)

3) 문제/해결 섹션
- 현재 문제 2~3개
- 해결 방식 요약 2~3개

4) 핵심 기능/혜택 섹션
- 기능 3~5개
- 기능별 짧은 설명(1~2문장)

5) 사회적 증거 섹션
- 수치/리뷰/사용 사례 중 택1

6) 작동 방식 섹션
- 3단계 프로세스

7) FAQ 섹션
- 5문항 내외

8) 최종 CTA 섹션
- CTA 버튼 1개
- 보조 문구 1줄

9) 푸터
- 정책 링크(이용약관/개인정보 처리방침)
- 문의 채널

## 3.1 IA 길이 가이드
- 히어로: H1 35자 이내, 서브 카피 90자 이내
- 기능/혜택: 카드당 30~60자
- FAQ: 문항당 80~140자

## 4. 카피 가이드
- H1: 35자 이내, 핵심 가치 1개만 강조
- 서브 카피: 60~90자, 문제-해결-성과 흐름
- CTA: 행동 중심(예: "지금 시작하기")
- 금지: 과장, 모호한 표현, 중복 주장

## 4.1 카피 초안 템플릿
- H1: {핵심 가치}로 {사용자 문제}를 {시간/비용} 단축
- 서브 카피: {문제}로 낭비되는 {시간/비용}을 줄이고, {해결 방식}으로 {성과}를 얻습니다.
- CTA: 지금 시작하기 / 무료로 확인하기

## 5. 메타/OG 기준
### 5.1 기본 메타
- Title: 40~60자
- Description: 80~120자
- Canonical: 랜딩 대표 URL 고정

### 5.2 Open Graph/Twitter
- og:title, og:description, og:image, og:url 필수
- twitter:card, twitter:title, twitter:description, twitter:image 필수

### 5.3 메타 샘플
- Title: 씨씨카지노 | 한 페이지로 핵심 기능 정리
- Description: 씨씨카지노(씨씨 카지노) 서비스 소개 랜딩. 핵심 기능과 이용 흐름을 한 페이지로 정리합니다.

## 6. 구조화 데이터(JSON-LD)
- WebSite + Organization 기본 적용
- WebPage 타입으로 랜딩 페이지 정의

### 6.1 JSON-LD 샘플
```json
{
	"@context": "https://schema.org",
	"@type": "WebPage",
	"name": "씨씨카지노",
	"url": "https://cc-jm.com/"
}
```

- 내부 링크는 핵심 랜딩으로 수렴
- 이미지 대체 텍스트 필수
