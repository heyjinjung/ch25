## 1. 목적
본 문서는 XMAS Event System의 대외 공개 웹(랜딩/마케팅/블로그) SEO 운영 기준과 기술 기준을 정의한다.

## 2. 범위
- 대상: 대외 공개 웹(랜딩 페이지, 마케팅 페이지, 블로그/뉴스)
- 제외: 인앱/로그인 이후 페이지, 내부 전용 페이지
- 목표: 구글 검색 반영을 최우선으로 한다.
- 측정: 로그 기반 지표를 표준으로 사용한다.

## 3. 용어 정의
- SEO: 검색 엔진 최적화
- 인덱싱: 검색 엔진이 페이지를 검색 결과에 반영하는 과정
- 크롤링: 검색 엔진이 페이지를 수집하는 과정
- 캐노니컬: 중복 페이지의 대표 URL 지정
- 구조화 데이터: schema.org 기반 JSON-LD

## 4. SoT 우선순위
- 본 문서가 대외 공개 웹 SEO의 최우선 기준이다.
- 충돌 시 최신 버전의 SEO SoT 문서를 우선한다.

## 5. 운영 목표
1) 구글 검색 반영(인덱싱) 확보
2) 핵심 랜딩 페이지의 노출 및 CTR 개선
3) 페이지 품질 신호(성능/콘텐츠/링크) 강화

## 6. 대상 페이지 정책
- 필수: 핵심 랜딩 페이지 1종을 SEO 표준에 맞춰 제작한다.
- 권장: 블로그/뉴스형 콘텐츠 페이지를 템플릿화하여 확장한다.
- 금지: 로그인 필요 페이지, 세션 의존 페이지를 SEO 대상으로 등록하지 않는다.

## 7. 기술 SEO 기준
### 7.1 메타데이터
- 각 페이지는 고유한 `title`과 `meta description`을 갖는다.
- Open Graph, Twitter 카드 메타는 필수로 포함한다.

### 7.2 인덱싱/크롤링
- `robots.txt`는 공개 페이지 크롤링을 허용한다.
- 사이트맵을 제공하고, 변경 시 갱신한다.
- 200/301/404 상태코드는 목적에 맞게 운영한다.

### 7.3 캐노니컬
- 중복 가능성이 있는 페이지는 대표 URL을 `canonical`로 고정한다.

### 7.4 구조화 데이터
- 기본 유형: Organization, WebSite
- 콘텐츠 유형 페이지는 Article/BlogPosting을 적용한다.

### 7.5 성능 기준
- LCP, CLS, INP 등 핵심 웹 바이탈 개선을 우선순위로 둔다.
- 이미지/폰트/스크립트 최적화를 상시 적용한다.

## 8. 콘텐츠/정보 구조 기준
- H1은 페이지당 1개를 유지한다.
- 내부 링크는 핵심 랜딩으로 수렴하도록 구성한다.
- 중복/빈약/자동 생성 콘텐츠는 금지한다.

## 9. 측정/검증 기준 (로그 기반)
- 필수 수집: 요청 URL, 상태코드, 유입 경로(referrer), UA/봇 여부, 응답시간
- 지표: 크롤러 방문 횟수, 인덱싱 대상 URL 수, 200/404 비율, 평균 응답시간
- 리포트 주기: 주간 요약, 월간 트렌드 비교

## 10. 변경 관리
- SEO 정책 변경 시 변경로그에 이유/적용일을 기록한다.
- 사이트맵/robots/메타 정책 변경은 QA 체크리스트를 통과해야 한다.
