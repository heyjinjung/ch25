## 1. 개요 (Overview)
V2 관리자 시스템은 단순한 데이터 편집 도구가 아니라, 실시간 위기/기회 요소를 감지하고 즉각 개입(Intervention)할 수 있는 **CRM 중심의 관제 센터**이다.

## 2. 디자인 및 UX 표준 (Soft Obsidian)
- **테마 컬러**: 완전한 블랙이 아닌 Warm Dark 테마인 `#121214`를 사용한다.
- **모바일 우선 (Mobile First)**: 모든 액션은 아이폰/갤럭시 환경에서 한 손으로 조작 가능해야 한다. (Bottom Dock 메뉴 적용)
- **안전 장치**: 터치 실수를 방지하기 위해 출금 승인 등 중요 액션은 **'밀어서 승인' (Slide-to-Approve)** 방식을 사용한다.
- **디자인 밀도**: 가독성을 위해 요소 간 간격을 8px로 최적화한다.

## 3. 게임 설정 및 장애 방어 (Game Config & Fail-safe)
### 3.1 설정 스키마 (Standard Schema)
- **룰렛**: 8개 세그먼트(0~7) 고정. `ticket_type`만으로 등급을 구분하며, `grade` 필드는 폐기(Deprecated)한다.
- **복권**: 가중치(`weight`) 및 재고(`stock`) 기반의 당첨 로직을 따른다.
- **보상 정규화**: `POINT`는 저장 시 `VAULT`로 표시하며, 레거시는 `NONE`으로 강제 변환한다.

### 3.2 장애 대응 원칙 (2026-01-25 기록 기반)
- **Fail-safe**: 설정 누락(None/Null) 시 500 에러를 뱉는 대신, **200 OK와 빈 데이터**를 반환하여 UI 멈춤을 방지한다.
- **데이터 무결성**: 게임 플레이 시 티켓 차감과 보상 지급의 원자적(Atomic) 처리를 보장해야 한다.

## 4. 핵심 분석 도구 (Golden Radar)
- **위기 감지**: 5연속 패배 또는 잔액 50% 급감 유저를 실시간 점멸(`PulsatingDot`) 신호로 표시한다.
- **기회 감지**: 골든타임 활성 유저 및 고액 배팅 유저를 추적하여 마케팅 세그먼트에 자동 편입한다.
