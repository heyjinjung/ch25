# 2026-01-28: Marketing-Psychology 스킬 학습 및 XMAS Event System 적용

## 스킬 개요
- **이름**: marketing-psychology
- **설명**: 행동 과학과 멘탈 모델을 마케팅 의사결정에 적용, 심리적 레버리지 점수(PLFS)로 우선순위화.
- **역할**: 윤리적이고 실용적으로 행동 변화 유도 (참여, 보상 청구, 유지 최적화).

## 주요 내용 요약
- **PLFS 점수화**: Leverage, Fit, Ease, Speed, Ethics 차원으로 모델 평가 (범위 -5~+15).
- **멘탈 모델 라이브러리**: Paradox of Choice, Loss Aversion, Social Proof 등 140+ 모델.
- **출력 형식**: 모델별 PLFS, 적용 방법, 테스트, 윤리 가드레일.
- **여정 편향**: Awareness/Consideration/Decision/Retention 단계별 모델 선택.
- **윤리 가드레일**: 다크 패턴, 거짓 희소성 금지.

## XMAS Event System 적용
### 프로젝트 컨텍스트
- 이벤트/게임 앱: 룰렛, 다이스, 보상 시스템.
- 타겟 행동: 참여(플레이), 보상 청구(금고/티켓), 유지(팀배틀/시즌).
- 제약: Rate Limit, 금고 정책, KST 09:00 리셋.

### 추천 모델 (PLFS 기반, 최대 5개)
1. **Loss Aversion (+12)**: 보상 손실 프레이밍 ("지금 청구 안 하면 티켓 잃음").
   - 적용: UI 팝업, 백엔드 알림.
   - 테스트: A/B (참여율).
   - 윤리: 강요 금지.

2. **Social Proof (+10)**: 참여자 수/리뷰 표시로 신뢰 ↑.
   - 적용: 실시간 카운터, 리뷰 섹션.
   - 테스트: 표시 vs 미표시 (가입율).
   - 윤리: 실제 데이터만.

3. **Default Effect (+9)**: 기본 옵션으로 쉬운 선택 (룰렛 자동 참여).
   - 적용: UI 기본 체크.
   - 테스트: 기본 vs 수동.
   - 윤리: 투명성.

4. **Endowment Effect (+11)**: 소유감 강조 ("내 보상").
   - 적용: "귀하의 티켓" 메시지.
   - 테스트: 메시지 vs 일반.
   - 윤리: Rate Limit 준수.

5. **Scarcity (+10)**: 희소성 강조 ("남은 플레이 2회").
   - 적용: 배너, 이벤트 타이머.
   - 테스트: 표시 vs 미표시.
   - 윤리: 실제 제한.

### 실행 계획
- **PLAN**: 컨텍스트 분석, 모델 선별.
- **PATCH**: UI/백엔드 구현 (React + FastAPI).
- **VERIFY**: 정책 준수, 빌드 테스트.
- **SHIP**: A/B 테스트, 모니터링 (참여율 지표).

## 결론
심리 모델로 사용자 행동 최적화 가능. 윤리 우선, 테스트 기반 적용 추천.
