## 1. 개요

외부 게임 로그 CSV를 V2 시스템에 임포트하여:
- 실시간 게임 이벤트 분석
- 연패/연승 패턴 감지
- 이탈 위험 유저 식별
- 수익/지출 분석

## 2. CSV 포맷 SoT

### 2.1 Game Log CSV 컬럼
| 컬럼 | 타입 | 설명 | 예시 |
|------|------|------|------|
| `기록 일시` | datetime | 게임 실행 시각 (ISO8601) | 2026-02-01T10:00:00Z |
| `유저 ID` | int | V2 유저 ID | 101 |
| `게임 종류` | string | 게임 타입 | DICE, ROULETTE, SLOT, POKER |
| `결과` | string | 게임 결과 | WIN, LOSE, DRAW, JACKPOT |
| `배팅 금액` | int | 배팅액 (원) | 1000 |
| `지급 금액` | int | 당첨액 (원) | 0 |
| `게임 후 잔액` | int | 게임 후 잔액 | 50000 |
| `외부 아이디` | string | 외부 시스템 ID | ext_user_001 |
| `세션 ID` | string | 게임 세션 | sess_999 |
| `기타 정보` | JSON | 추가 메타데이터 | {"dice_value": 3} |

## 3. 데이터 활용 영역

### 3.1 분석 대시보드 연동
| 지표 | 계산 방식 | 데이터 소스 |
|------|----------|-------------|
| **오늘 수익** | SUM(배팅 금액) - SUM(지급 금액) | Game Log |
| **오늘 지출** | SUM(지급 금액) | Game Log |
| **순수익** | 수익 - 지출 | Game Log |
| **주간 성장률** | (이번주 - 전주) / 전주 * 100 | Game Log |

### 3.2 실시간 모니터링 연동
| 모니터링 항목 | 트리거 조건 | 액션 |
|--------------|------------|------|
| **연패 감지** | 5연속 LOSE | `TRG_LOSE_5` 개입 |
| **잔액 급감** | 잔액 50% 이상 감소 | `TRG_BAL_DROP_50` 개입 |
| **고액 배팅** | 배팅액 100만원+ | 고액 유저 마킹 |
| **잭팟 당첨** | JACKPOT 결과 | VIP 승격 검토 |

### 3.3 이탈 위험 레이더 연동
```python
def detect_churn_risk(user_id: int, game_logs: List[GameLog]) -> str:
    """
    게임 로그 기반 이탈 위험도 분석
    
    Returns:
        'HIGH': 즉시 개입 필요
        'MEDIUM': 모니터링 필요
        'LOW': 정상
    """
    recent_logs = game_logs[-10:]  # 최근 10게임
    
    lose_count = sum(1 for log in recent_logs if log.result == 'LOSE')
    total_loss = sum(log.bet_amount - log.payout for log in recent_logs)
    
    if lose_count >= 7 or total_loss > 500_000:
        return 'HIGH'
    elif lose_count >= 5 or total_loss > 200_000:
        return 'MEDIUM'
    else:
        return 'LOW'
```

## 5. API 엔드포인트

### 5.1 CSV Import
```
POST /api/v2/admin/csv/import
Content-Type: multipart/form-data

{
  "file_path": "path/to/game_log.csv",
  "import_type": "GAME_LOG",
  "batch_size": 250,
  "emit_to_redis": true,
  "historical_mode": false
}
```

### 5.2 게임 로그 조회
```
GET /api/v2/admin/game-logs?user_id={user_id}&limit=100
```

### 5.3 분석 통계
```
GET /api/v2/admin/analytics/game-summary?date=2026-02-01
```
