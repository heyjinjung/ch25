# Golden 프로젝트: AI 프롬프트 활용 지침 (v1)

본 문서는 **Golden 프로젝트 문서(전략/기술/리서치)**를 기반으로, 앞으로 AI에게 요청할 때 **일관되고 재현 가능한 결과**를 얻기 위한 프롬프트 운영 기준입니다.

---

## 1) 목적 (Why)
- 리텐션 개선안/카피/실행 플랜을 **프로젝트 철학과 제약**에 맞춰 빠르게 도출.
- 운영/기획/개발이 **같은 언어**로 AI 결과물을 평가할 수 있도록 표준화.

---

## 2) 필수 컨텍스트 (항상 포함)
아래 6가지는 **항상 프롬프트에 포함**합니다.

1. **대상 유저/상황**
   - 예: “KST 20~40대 남성, 티켓 0 상태, 금고 잠김 메시지 노출 직전”
2. **목표 지표**
   - 예: “D1 리텐션 ↑, Ticket Zero 전환율 ↑, 시즌패스 클레임율 ↑”
3. **리텐션 레이어/엔진**
   - Sentiment / Engagement / Wallet / Reaction 중 선택 + 필요한 엔진(퀘스트/마이크로 콜로세움/개입 트리거)
4. **채널/노출 위치**
   - 예: 홈 카드, Ticket Zero 모달, 시즌패스 임박 배너, 팀 배틀 열세 토스트
5. **제약 조건**
   - 항상-on 구조(게이트 폐기), KST 기준, 금액 정수 표기, 푸시 미사용(인앱 중심)
6. **톤/금지어**
   - 금고 카피 금지어: “보상/이벤트/참여/충전하세요”
   - 지향어: “보관 중/소멸 예정/남은 시간/내 자산”

---

## 3) 출력 포맷 규칙 (AI 응답 형식)
아래 포맷으로 요청합니다.

- **아이디어/전략 요청**
  1) 핵심 아이디어 (1~2줄)
  2) 기대 효과 (정성 + 지표 1개)
  3) 적용 위치
  4) 난이도 (낮음/중간/높음)

- **카피/문구 요청**
  - A/B 문구 3쌍
  - 1줄 요약 + CTA 1개
  - 금고 카피 금지어 체크

- **기술 설계 요청**
  1) 필요 데이터 필드
  2) 트리거 조건
  3) 액션(보상/노출)
  4) 실패 시 폴백

---

## 4) 프롬프트 템플릿

### A) 리텐션 아이디어 생성
```
[Golden/Idea]
대상: {유저군/상황}
목표: {지표}
레이어: {Sentiment|Engagement|Wallet|Reaction}
엔진: {Quest|Micro-Colosseum|Intervention}
채널: {노출 위치}
제약: {항상-on, KST, 정수 금액, 인앱만}
출력: 아이디어 5개 (효과/위치/난이도 포함)
```

### B) 카피라이팅 생성
```
[Golden/Copy]
상황: {Ticket Zero|Vault 임박|팀 배틀 열세}
톤: {다크 카지노, 짧고 직설적}
금지어: {보상, 이벤트, 참여, 충전}
출력: A/B 3쌍 + CTA 1개
```

### C) 기술 설계 초안
```
[Golden/Spec]
목표: {골디락스 존 유지}
데이터: {loss_streak, balance_drop, prime_time}
트리거: {조건}
액션: {보상/노출}
출력: 필드/트리거/액션/폴백
```

---

## 5) Do / Don’t

**Do**
- Golden 레코드 4레이어(Sentiment/Engagement/Wallet/Reaction) 기준으로 제안
- Ticket Zero/금고/팀 배틀/시즌패스 **실제 노출 지점**에 맞춘 제안
- 지표와 연결된 실행 플랜 제시

**Don’t**
- 푸시/DM 전제 제안 (현재 미지원)
- today-feature 게이트 가정
- 금액 포맷에 쉼표/소수점 사용
