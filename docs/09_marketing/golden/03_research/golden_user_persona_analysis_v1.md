# 유저 페르소나 분석 및 맞춤형 리텐션 전략

본 문서는 유저의 행동 패턴에 따른 페르소나(High-risk vs Safe) 구분 로직과 각 그룹별 리텐션 극대화 전략을 제안합니다.

---

## 1. 페르소나 구분을 위한 분석 로직

### A. 구분 지표 (Segmentation Metrics)

| 구분 지표 | 고위험 유저 (One-shot Seekers) | 안전형 유저 (Long-term Players) |
| :--- | :--- | :--- |
| **베팅 규모 변동성** | 매우 높음 (급격한 금액 변화) | 매우 낮음 (일정한 베팅 유지) |
| **자산 대비 베팅 비율** | 높음 (보유 자산의 50% 이상 투입) | 낮음 (보유 자산의 5% 미만 쪼개기) |
| **게임 선택 선호도** | 고위험·고수익 (슬롯, 고액 룰렛) | 저위험·사교형 (팀 배틀, 소액 게임) |
| **세션 및 방문 패턴** | 짧고 강렬함 (자산 소진 시 이탈) | 길고 꾸준함 (일일 미션 달성 위주) |
| **RFM 프로필** | M(Monetary) 중심 | F(Frequency), R(Recency) 중심 |

### B. 시스템 구현 로직 (Detection Logic)

*   **고위험군(Tilted/High-roller) 탐지**: 
    - 조건: `last_win_loss_streak` < 0 AND (`bet_size_variation` > 200% OR `bet` > `asset` * 0.5)
    - 태그: **'손실 복구형 고위험 유저'**
*   **안전형군(Loyal/Casual) 탐지**:
    - 조건: `frequency` >= 7일 연속 AND `avg_bet` < `asset` * 0.05
    - 태그: **'캐주얼 충성 유저'**

## 2. 페르소나별 리텐션 마케팅 전략

### ① 고위험 유저: "독점적 대우와 VIP 경험"
*   **메시지**: "프로 플레이어님 전용 토너먼트", "연패 루프 단절 캐시백 혜택".
*   **보상**: 
    - VIP 티어 업그레이드 및 높은 출금 한도.
    - 자산 급감 시 선호 게임의 '무료 스핀' 즉시 발급 (Win-back).
    - 프리미엄 오퍼 (현실 연계 보상).

### ② 안전형 유저: "성취감과 커뮤니티"
*   **메시지**: "미션 완료 임박 알림", "팀 배틀 기여 요청".
*   **보상**: 
    - 게이미피케이션 (XP, 업적 배지) 강화.
    - 일일 미션 보상 (티켓, 소액 토큰).
    - 커뮤니티 소속감 (전용 채팅방, 리더보드 노출).

---

## 3. 공통 리텐션 로직 (골디락스 존 유지)

1.  **실시간 난이도 조절(DDA)**: 좌절(High-risk) 또는 지루함(Safe) 감지 시 게임 메카닉 미세 조정.
2.  **가변 보상 스케줄**: 예측 불가능한 시점의 보너스로 도파민 반응 유도.
3.  **책임감 있는 도박(RG) 도구**: 지출 한도 설정 기능 제공을 통한 장기적 신뢰 형성.

---

## 4. 결론
고위험 유저는 **VIP 특별 대우**로, 안전형 유저는 **성장 서사와 소속감**으로 관리하여 수익성과 리텐션을 동시에 확보합니다.
