# 골디락스 존 개입 A/B 테스트 프레임워크 (v1)

본 문서는 **연패/자산 급감 상태에 대한 개입 전략**의 효과를 과학적으로 비교하기 위한 A/B 테스트 설계 기준을 정의합니다.

---

## 1) 테스트 목적 및 핵심 지표(KPI)

### 목적
- 유저가 **연속 패배** 또는 **지루함**으로 이탈하는 것을 방지

### 가설
- **유저가 5연패 또는 자산 50% 급감 상태일 때 즉각적인 가변 보상을 제공하면, 대조군 대비 리텐션이 향상된다.**

### KPI
- **리텐션**: D1, D7 유지율
- **행동 지표**: 평균 세션 시간(OT), 일일 접속 일수(OD), 베팅 빈도 변화
- **수익 지표**: ARPU, LTV

---

## 2) 실험군(Variants) 및 세그먼트 설계

### 타겟 세그먼트
- 실시간 감지(Redis/WebSocket)로 **5연패 또는 자산 급감**이 확인된 유저군

### 테스트 변형
- **대조군 (Control)**: 개입 없음 (기존 시스템 유지)
- **실험군 A (Free Spins)**: 즉각 무료 스핀 지급
- **실험군 B (Cashback)**: 손실 일부 즉시 복구
- **실험군 C (Special Mission)**: “3판 더 플레이 시 토큰 지급” 단기 목표

### 분배 방식 (운영 기본값)
- Control 25% / FreeSpin 25% / Cashback 25% / Mission 25%
- 유저 `user_id` 해시 버킷으로 **항상 동일 그룹** 고정

---

## 3) 통계 기준 및 샘플 크기

### 유의성 기준
- **p-value < 0.01 (또는 0.05)** 기준으로 유의미한 차이 판단

### 샘플 크기 가이드
- 최소 **수천 명 이상** 권장
- 고위험 유저(High Roller)는 데이터 희소성으로 **모니터링 기간 연장** 필요
- 대규모 트래픽인 경우 **군당 25% 균등 배분** 권장

---

## 4) 대시보드 시각화/분석

### 필수 차트
- **코호트 분석 테이블**: 개입 시점 기준 잔존율 비교
- **실시간 세션 메트릭 그래프**: 개입 직후 이탈률/베팅 회복 추이
- **혼동 행렬(Confusion Matrix)**: 예측 이탈 위험군 vs 실제 이탈
- **ROI 리프트 분석**: 보상 비용 대비 LTV 방어 효과

이 프레임워크는 **밀리초 단위 개입**을 **통계적으로 검증**하여, 시스템을 “살아있는 유기체”로 진화시키는 핵심 실험 체계입니다.
