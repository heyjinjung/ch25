# 외부 배팅 로그 기반 리텐션 신호 추출 전략

제공해주신 로그(에볼루션, 스포츠 배팅)는 우리가 찾던 **"골든 레코드(Golden Record)"** 그 자체입니다.
"데이터 양이 너무 많지 않을까"라는 우려는 **"가공 후 폐기(Process & Discard)"** 전략으로 해결할 수 있습니다.

## 1. 로그 분석: "보물은 이미 있다"

제공해주신 데이터를 분석해보면, 우리가 기획한 **'감정(Sentiment)'** 신호를 바로 뽑아낼 수 있습니다.

### 사례 분석: 유저 `짱맨 (hook88)`
*   **시간**: 2026/01/17 17:55 ~ 17:57 (약 2분간)
*   **로그 흐름**:
    1.  17:55:28 베팅 20,000 -> 17:55:35 결과 **0원 (패)**
    2.  17:55:54 베팅 10,000 -> 17:56:02 결과 **0원 (패)**
    3.  17:56:21 베팅 100,000 -> 17:56:26 결과 **0원 (패)** (올인 추정? 금액 급증)
    4.  17:57:01 베팅 10,000 -> 17:57:16 결과 **0원 (패)**
    5.  17:57:34 베팅 115,000 -> 17:57:44 결과 **0원 (패)** (분노 베팅?)

> **진단**: 이 유저는 2분 만에 **5연패**를 당했고, 베팅 금액이 1만->10만->11만으로 널뛰기하고 있습니다. 전형적인 **"틸팅(멘탈 붕괴)"** 신호입니다. 지금 개입하지 않으면 이탈합니다.

---

## 2. "데이터 홍수" 해결: 경량화 파이프라인

모든 로그를 DB에 저장할 필요가 없습니다. **"신호(Signal)"만** 남기고 로그는 버립니다.

### 아키텍처: `Log Swallow` (로그 삼키기)

1.  **수집 (Ingest)**: 외부 API/CSV에서 로그를 긁어옵니다. (1분 단위)
2.  **가공 (Digest)**: 스크립트가 메모리에서 계산합니다.
    *   `hook88`의 현재 연패수: 4 -> **5** (업데이트)
    *   `hook88`의 금일 손실액: -130,000 -> **-245,000** (업데이트)
3.  **트리거 (Trigger)**:
    *   `IF 연패수 >= 5`: **"위로금 알림"** 발송 큐에 넣음.
4.  **폐기 (Discard)**: 원본 로그는 압축해서 S3(저비용 스토리지)에 던지거나 삭제합니다. 메인 DB에는 들어가지 않습니다.

### 데이터베이스 부하 예측
*   **Before**: 하루 10만 건 로그 Insert -> DB 폭발 💥
*   **After**: 하루 0건 로그 Insert. 오직 Redis(메모리)에서 숫자(`streak_count`)만 +1 수정 -> 부하 0에 수렴 🍃

## 3. 구현 제안: `ExternalLogParser.py`

복잡한 시스템 개발 없이, 간단한 파이썬 스크립트로 시작할 수 있습니다.

### 1단계: CSV/API 파싱
```python
# 가상 코드 예시
def process_log(row):
    user_id = row['닉네임']
    bet_amount = row['베팅금액']
    win_amount = row['당첨금액']
    
    if win_amount == 0:
        # 패배 시: 레디스에서 연패 카운트 증가
        redis.incr(f"user:{user_id}:loss_streak")
        current_streak = redis.get(f"user:{user_id}:loss_streak")
        
        # 5연패 체크
        if int(current_streak) == 5:
            send_bailout_message(user_id)
    else:
        # 승리 시: 연패 카운트 리셋
        redis.set(f"user:{user_id}:loss_streak", 0)
```

### 2단계: 운영 적용
1.  운영팀이 10분마다 외부 페이지에서 엑셀/로그를 긁어옵니다.
2.  이 스크립트에 넣습니다.
3.  스크립트가 자동으로 "구제 대상 유저" 리스트를 뽑아줍니다.
4.  (나중에는 이 과정 전체를 자동화)
