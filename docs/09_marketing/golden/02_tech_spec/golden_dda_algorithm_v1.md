# 동적 난이도 조절(DDA) 알고리즘 설계서

유저를 '골디락스 존(Goldilocks Zone)'에 유지하기 위한 실시간 난이도 조절 시스템 설계입니다.

---

## 1. DDA 알고리즘 핵심 원리

### A. 실시간 작동 방식
1.  **사용자 상태 분석**: 정확도, 수행 시간, 승패 기록 등 지속 모니터링.
2.  **실시간 개입**: 좌절 감지 시 난이도 하향 또는 힌트 제공. 지루함 감지 시 난이도 상향.
3.  **협업 필터링**: 유사 유저 데이터 기반 최적 다음 퀘스트 예측.

### B. 수학적 모델링

#### 로지스틱 진행 모델 (Logistic Progression)
```
D(x) = D_max / (1 + e^(-γ(x - x₀)))
```
*   `D(x)`: 레벨 x에서의 난이도
*   `γ`: 난이도 상승 속도 제어 파라미터
*   `x₀`: 난이도 곡선 중심점

#### 플로우 이론 모델 (Flow Theory)
```
C(x) = s(x) + k
```
*   `C(x)`: 도전 수준
*   `s(x)`: 유저 실력
*   `k`: 실력 대비 도전 수준 오프셋 상수

## 2. ch25 시스템 적용 로직

### A. 트리거 조건
| 상태 | 조건 | 개입 |
| :--- | :--- | :--- |
| **좌절(Frustrated)** | `streak` <= -5 OR `balance_delta` >= 50% | 승률 보정 버프 적용 |
| **지루함(Bored)** | `streak` >= +5 AND 세션 > 30분 | 고난이도 미션 제안 |
| **몰입(In-flow)** | -3 < `streak` < +3 | 현 상태 유지 |

#### 승/패 판정 기준 (SoT)
- **패배(LOSS)**: `reward_type = NONE` (꽝/무보상만 패배)
- **승리(WIN)**: 그 외 모든 `reward_type` (티켓/토큰 포함)

### B. 승률 보정 버프 (Soft Landing)
*   **적용 대상**: `current_win_loss_streak` <= -5인 유저
*   **알고리즘**: 주사위/룰렛 결과 판정 시 Hidden Bonus 가산
    ```python
    if user.streak <= -5:
        win_chance += 0.05  # 5% 승률 보정
    ```
*   **제한**: 최대 3회 연속 적용 후 리셋 (악용 방지)

## 3. 고도화 기법

### A. 텐서 분해 (Tensor Decomposition)
*   유저의 시간에 따른 스킬 숙련도 정밀 계산 (93% 정확도).

### B. 강화 학습 (Reinforcement Learning)
*   시스템이 '유저 몰입 유지' 행동 선택 시 보상 획득 → 개입 전략 자가 최적화.

---

## 4. 리텐션 효과

*   **초기 이탈 방지**: 초보 유저의 갑작스러운 좌절 방지.
*   **LTV 극대화**: 적절한 성취감 → 장기 체류 → 수익성 증대.
*   **지능형 커머스 연동**: 연패 시 인벤토리에서 도움 아이템 자동 추천.
