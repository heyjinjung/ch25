## 추가 업데이트 (2026-01-13)

### 6) CI 기반 자동 배포 게이트 안정화(502/401)
- GitHub Actions 배포 워크플로에 배포 게이트를 고정했다: DB 덤프(0바이트 방지) → compose up → 마이그레이션 → 헬스(backend 내부 → nginx 경유) → 어드민 스모크.
- 운영 환경에서 간헐적으로 발생하는 nginx 502는 배포 직후 **nginx 1회 restart**로 흡수하도록 워크플로에 반영했다.
- 어드민 스모크는 인증 정책 때문에 401이 정상일 수 있어, **200(JSON)** 또는 **401(JSON + AUTH_REQUIRED)** 을 정상으로 허용하고 HTML 응답은 실패로 판정하도록 개선했다.
- 근거 파일: `.github/workflows/deploy.yml`

### 7) HTTPS 접속 불가(ERR_CONNECTION_CLOSED) 복구
- 증상: 80은 301 리다이렉트되지만 443 TLS handshake가 끊겨 접속 불가.
- 원인/조치: nginx 설정에서 443 SSL server block이 비활성(주석) 상태였고 인증서는 존재하여, 443 블록을 활성화해 정상화.
- 검증: `https://cc-jm.com/health` 200.
- 근거 파일: `nginx/nginx.conf`

### 8) 관리자 유저 수정 PUT 500 (user_identity_history 테이블 누락)
- 증상: 어드민 유저 수정 `PUT /admin/api/users/{id}`가 500.
- 원인: 변경 이력 기록을 위한 `user_identity_history` INSERT 수행 중, 운영 DB에 테이블이 없어 실패.
- 조치: Alembic 마이그레이션으로 테이블 생성(영구 해결) + 운영 DB는 즉시 DDL로 핫픽스하여 장애를 차단.
- 근거 파일: `alembic/versions/20260113_0930_add_user_identity_history.py`
